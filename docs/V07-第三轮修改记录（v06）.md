# v06 第三轮修改记录（事实层优先）

> 指令：《AgriLink 农链 — 第三轮修改指令（v05 → v06）》；本轮**只改事实层与两层共用框架**，事实详情排版/关联层/推演层未动。

## 一、底部流水

| 项 | 处理 |
| --- | --- |
| B1 节奏太机械 | 重写调度：成批 3–5 条快速刷过（条间 90–170ms）→ 停顿 1–2.2s；另有「长处理」路径（单条出现后停留 1.5–2.4s 再继续）；零散处理 260–1160ms |
| B2 单条内容太短 | 改为长格式：`[YYYY-MM-DD HH:mm:ss.SSS] ◆ 阶段 \| 来源:… \| 标题:… \| 可信度:… \| 影响:… \| 坐标:[lng,lat] \| 受影响区域:…(半径约 Nkm) \| 关联本体:… \| 证据:N 条 \| 来源级别:X 级 \| 处理链路:… \| 处理耗时:Nms ✓`；实测单条 240 字以上，超 800 字按指令截断并加 `...` |
| B3 亮星联动 | 新增 DOM 星闪（按指令给的 `starFlash` keyframes）：每条进入流水的事实向地图投一次闪光，0.9–1s 后自动移除；`severity` 高的事实为亮星（scale 1.5），一般为微闪（0.8）；不再长期发光、不循环 |

## 二、顶部导航

- T1 三 Tab：IBM Plex Sans SC、13px、水平居中紧凑；选中态改为**1.5px 细下划线** + 无强对比底色
- T2 右侧三图标：统一 Cursor 风格（1.5px 细线、`butt/miter` 无圆角、16px、`#8899aa` → hover `#556677`）；选中态为**微弱底色**（不再填充色块）
- T3 Logo：`🌾` 改为「风吹稻穗」式轻柔摇摆（±5°、2–3 个周期后停止）；品牌恢复为 **🌾 AgriLink v1.0**

## 三、左侧菜单

- L1 数据概览：只保留 **事实条数 + 整体可信占比**；数字 22px SemiBold、标签 11px Light、去掉了边框/卡片底
- L2 一级分类配色：统一为低饱和色（`#5b8ea6 / #6f9a6a / #5f9a94 / #b0736b / #8b7fa8 / #6f86b8 / #a08a63`），菜单标题、地图点、图例三方同色
- L3 面板毛玻璃：`background: rgba(255,255,255,.75)` + `backdrop-filter: blur(20px) saturate(160%)`，可透视地图
- L4 分类联动：取消任一三级类型 → 地图对应事实点立即消失，重新勾选立即恢复（自检通过）
- L5 快捷控制图标：全部替换为同一套 Cursor 风格图标

## 四、地图

- M1 毛玻璃恢复：顶栏 / 左侧菜单 / 右侧面板 / 抽屉 / 快捷键条 / 图例条全部 `backdrop-filter: blur(20px) saturate(160%)`；只有底部流水保持纯黑
- M2 地图交互：`roam: true`（滚轮缩放 + 拖拽平移）+ 双击放大 1.35×；交互后相机状态同步，缩放按钮与层级切换保持一致
- M3 快捷键条：移到**地图右下角**、去掉框线、毛玻璃底、每键有 tooltip、右侧面板打开时自动左移（`--side-w` 偏移）
- M4 图例：移到**地图底部居中**、单行横排、无框线、无「当前视野类型」等文字标题
- M5 图例内容：改为「地图上实际可见的类型」——一级分类色（按当前视野出现顺序）+ 产区/口岸标记说明；点击产区/口岸标记**直接在事实层展开本体详情**（不切换 Tab，实测 `tab=fact`、`factObj=e:base:hn-jingzhou`）
- M6 密度：改为空间漏斗——全球=全部事实（默认口径 224 点，各大洲均有）、中国=落入中国范围的事实（133 点）、省区=聚焦省区（湖南 72 点）；层越深局部越密
- M7 影响范围与大小：影响范围为淡色径向扩散圈（半径随 `severity`/影响等级），事实点 4–6px 且尺寸/亮度随 `severity` 递增

## 五、图标

全页面（顶栏 / 菜单 / 地图快捷键 / 图例 / 卡片）统一 Cursor 风格：1.5px 细线、无圆角、16px、`#8899aa` → hover `#556677`、选中为微弱底色。
