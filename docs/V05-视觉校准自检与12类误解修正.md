## 三、一票退回项逐条自检

| 退回项 | 结论 | 依据 |
| --- | --- | --- |
| 黑白暗色重设计 / 过高顶部栏 / 不可见按钮 | 通过 | 浅色基线（自检“视觉基线”）；顶部条 24px、热区 22px；图标全部可见线性 SVG |
| 全球/中国面包屑、操作教学、地图指标卡、事实类型分布 | 通过 | 四项删除断言全部为 0 命中 |
| 分类字典与 F3 / A2 不一致 | 通过 | F3：7/26/125 逐条来自指令表格；A2：九类对象域名称完全一致 |
| 图例进入菜单或竖向占大块地图 | 通过 | 图例在菜单外的底部横向条内；菜单内无图例 |
| 事实长期闪烁 / 产区·本体节点遮挡地图 | 通过 | 持久点为普通 scatter；结点尺寸 ≤11px、标签 9px 带白底；影响范围径向渐变低透明度 |
| 事实层出现事实关系线 | 通过 | 事实层地图无 lines/graph 系列 |
| 关联层独立关系清单 / 居中详情弹窗 / 关系线无方向 | 通过 | 右侧无关系清单；无 `.modal`；曲线 + 方向粒子 + 起止语义可点开 |
| 样例 / 示意 / 数据包 / L1-L2-L3 / 生成器 / 调试文案 | 通过 | 三层界面违禁词扫描 0 命中（含抽屉与流水） |
| 卡片文字溢出 / 按钮不可读 / 图标风格不统一 | 通过 | 卡片文字换行不截断（自检 + 人眼复核）；按钮 ≥22px 点击热区；全站同一套线性图标 |
| 未经确认直接发布线上版本 | 通过 | 本阶段**未发布**；原站与 `agri-llm-demo-v04` 均未改动，仅提交分支与截图 |

## 四、数据规则遵守情况

- 真实公开数据优先：产区 64 / 港口 56 / 机场 49 / 冷链节点 4 的经纬度来自公开地理数据；真实记录 90 条在适配层零改动（`V03_DEBUG.rebalanceSummary()` 可核验 `realUnchanged = 90/90`）。
- 生成数据在同一字段结构内、内部保留 `provenanceMeta.dataMode` 与来源登记；普通页面不显示“生成数据/样例”标签。
- 覆盖榴莲、樱桃与高价值蔬菜（`车厘子`、`榴莲`、`设施蔬菜` 等类型与事实均在数据内）；马来西亚榴莲流入红星市场占比与红星市场份额的贯通故事（`F-DU-0x` 与推演层场景）保持不变。

## 五、已知限制与待确认项（本阶段不做）

1. **真实直播未接入**：按指令“暂停真实直播接入”，当前 10 条视频/直播事实全部为静态降级卡片（显示降级原因 + 原始外链），未挂载任何播放器。
2. **复杂动效暂停**：仅保留与新数据接入相关的一次性瞬时闪光；MiroFish 式持续流光动画、时间轴播放等放到第三阶段。
3. **MiroFish 对照图为官方公开截图**：来源于其开源仓库 README 截图目录；如产品侧有更贴合的参考页（含连线细节），请指定，我按同一口径重出对照。
4. **关联层“环境与事件”对象域当前为 0 个对象**：数据包未注册该域实体，界面按空域呈现（不编造对象）。
5. 窄屏（390px）本阶段只做可用性自检，未交付截图（V2 第一阶段只要求 1440×900）。
