# V0.8.12 · 地图展示配色

- **配色 1（默认）**：参考 WFP HungerMap 的冰蓝海面与浅色陆地，海面 `#e5f2f6`、陆地 `#e8e9e5`、面板 `#ffffff`、操作蓝 `#007dbc`。在大屏上用低饱和的分区色区分地理区域。
- **配色 2**：海面 `#95bec9`、陆地 `#b2cecd`、面板 `#f9fcfb`、操作蓝 `#005f95`。这是较深的蓝绿色地图方案，面板与文字仍保持亮色环境下可读。
- 两套颜色与「昼/夜」无关；国家和省区的差异化浅色只用于区域辨识，**不代表饥饿指数、风险等级或其他实测指标**。只有具有明确含义的事实和关联使用相应类别色。
- 全球 2D 底图以西经 25° 为接缝重新生成投影坐标：以中国为视野中心，北美和南美在其右侧。真实地理坐标保留在原数据中，3D 地球继续使用原始经纬度。
- 参考：https://hungermap.wfp.org/food?w=ipc-phase-3&m=percentage
