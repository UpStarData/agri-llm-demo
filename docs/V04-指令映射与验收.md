# AgriLink V1.0 · 指令映射与验收（LLM-291）

本轮范围：**只重做事实层与关联层的页面、交互与数据装载**；不改智能体配置，不扩展推演层。
附件《AgriLink 农链 — 页面修改指令》逐条落点如下，**每一条都给出「完成 / 本期预留 / 阻塞」**。

- 页面：单文件离线 `index.html`（`node build.mjs` 生成，CSS/JS/地图 geo/字体全部内联，无外部请求）
- 启动：`npm run serve`（本地演示服务）或直接双击 `index.html`
- 验证：`npm test`（80 项断言 → `test/report-v03.md`）· `npm run shots`（截图 → `shots/v04-*.png`）· `npm run compare`（基线对照 → `shots/compare/`）

| 标识 | 含义 | 数量（本轮） | 取值位置 |
| --- | --- | --- | --- |
| `provenanceMeta.dataMode = real` | 真实公开来源记录：带 `sourceUrl` / 机构 / 采集日，`evidence` + `observations` 一一对应 | 事实 90 条 | `data/pkg/facts.json` |
| `provenanceMeta.dataMode = generated` | 按同一 schema 生成：位置锚定真实地理锚点，不冒充真实来源 | 事实 771 条 | 同上 |
| `geo/*.geojson` 的经纬度 | 真实公开地理数据（产区 / 港口 / 机场 / 节点） | 64 + 56 + 49 + 4 | `data/pkg/geo/` |

验收方式（浏览器控制台或测试脚本，普通界面不显示）：
