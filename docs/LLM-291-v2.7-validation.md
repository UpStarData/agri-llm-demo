## 全球恢复与增量

此前默认7天筛选只留下中国及马来西亚业务记录；其它历史业务资料仍在库内。默认改为“全部时间”，保留近期手动筛选；“全部时间”下旧点不再按30天兜底规则衰减到透明。原始日期不刷新、不冒充今日事件。既有可定位业务资料8,111条完整保留，含八省市增量。

新增 **5,018条** 世界银行 WDI 公开农业统计，覆盖 **210个国家/地区**，俄罗斯25条、加拿大27条。九种指标：谷物产量、谷物单产、作物/食品/畜牧业生产指数、可耕地面积、农林渔增加值比重、食品进口/出口占比。取各指标最新三个有值年度，限定2020–2025；不同国家披露时间不同。保留原年度与精度，不生成日度或逐笔交易。

- 原始API响应及指标说明冻结于 `data/pkg2/v27-global-source.json`；可由 `python3 tools/build-v27-global.py` 复建派生包。
- [世界银行指标API](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures)；[国家API及参考坐标](https://datahelpdesk.worldbank.org/knowledgebase/articles/898590-country-api-queries)。每条事实有精确国家/指标/年度原始URL。
- 坐标采用世界银行提供的国家首都参考坐标，**代表国家统计，不代表农场或交易发生点**；卡片摘要和溯源明确说明，`geoPrecision=region_only`。同地点合点，不用随机偏移伪造密度。
- 新资料仍参加约32秒的地理均衡分批显示；完整数据随单文件下载，不声称网络流式加载。

新增 **26条红星独立公开事实**：甘味果蔬产销、2025年度交易统计、平台运营、榴莲周度监测、玉林合作、车厘子开柜/电商/顺丰合作。统计期和活动日期写明；经销商基地不冒充集团自有项目，未新增无证据贸易边或企业。沿用红星全球农批中心真实参考坐标，多条资料合点；同时写入既有红星/商品本体详情的支持事实。

## 关联闪动：复现、修复、连续帧验证

旧版本已有“无全量重建/无空节点”测试通过，但这不足以证明连续画面稳定。新增检查在V2.6.1真实页面上复现：首入全球前3.5秒，飞线系列提交53次、同ID路径改变202次、父层/画布低透明帧37次。问题是入场计时每60ms把正在运行粒子的终点改成尚未长完的曲线端点，加上父层和画布重复淡入。

- 飞线粒子从首绘就使用完整最终路径；节点/静态线的渐入不再改写飞线。保持重点线可见、底线淡隐及点击关系详情。
- 移除关联层整层 opacity/scale 动画及2D/3D切换时双重淡出。地球首个合成帧前同步画出不透明背景。
- 分批载入只追加可见节点，已有节点ID顺序保持；仅明确的聚焦/新入库重点对象可替换末尾普通样本。地球保留旧ID对应入场延迟，不因新批次重排而熄灭。
- 关联度按数据版本缓存，避免每个节点反复扫描全部关系。
- 同一事实列表和地域的地图/卡片共用筛选缓存；切层首绘后只补基于新坐标变换的光晕，不再次提交整批事实点。

两层历史取景不变：全球 `[107.98,26.65] ×1.36`，中国 `[108.05,36.15] ×1.59`，湖南 `[111.73,27.54] ×9.08`。

- `npm run test:v27`：四项数据与默认开关、两层全球覆盖、三视角3.5秒逐帧飞线路径/节点/opacity检查；继续执行20种关系40次筛选点击、编号单店库与入库隔离、八省市、地图类型、历史取景、红星网络及实际关系/粒子点击回归。
- `node test/v27-batches.mjs`：不加速的32秒地理分批、批次中已亮节点稳定性、3D首次画面不透明，以及完整载入后的切换/缩放性能分开记录。
- `node test/v26-delivery.mjs`：两层六个2D视角及两个3D视角自然接入星闪与右卡通知。
- `npm run test:all`：原影响半径、循环地图、拖动同步、动画实例及入库去重回归。
- 截图/运行报告写入忽略的 `test/artifacts/v27/`；不以程序断言替代同一交付验收智能体在线复验。启动/分批处理与用户交互的长任务分别记录，不承诺所有启动工作低于100ms。

本机自然批次样本：32.072秒完成，批次期间采样1,006帧，空节点画面0、整图低透明画面0；单次最多替换3个循环副本，对应一个真正新入库的优先本体。地球首入低透明/空白帧0，保持600个业务节点。启动长任务最大213ms，批次处理最大58ms，完整载入后切换/缩放没有观测到≥50ms长任务。更密集的六视角连续切换+拖动压力样本：帧间隔P95 33.4ms、最大166.6ms、最慢切换134.5ms。以上为本机测量，未宣称所有设备/操作都低于100ms。
