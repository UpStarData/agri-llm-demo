# LLM-291 V2.2 验证记录

本轮对应 2026-10-15 六项反馈。继续 V2.1 源码分支，独立提交 V2.2，不修改 main 或线上发布目录。

## 修改与复测

1. **湖南蓝底**：原光晕间距用像素比较，却把经纬度存入已占位置；首次转换还使用前一层投影。先安装当前 geo，再计算屏幕间距，所有光晕都登记像素位置，最大直径限制为 88px。冷启动湖南和返回湖南均为 12 个光晕，最小间距 56.7px；同次采样全球 6、中国 8。数量随视野/筛选变化，不再以旧版本的 24/23/18 作为实际数量。
2. **全球事实**：新增六洲 87 个地点 × 7 天，共 609 条气象再分析，事实总量 1543。中国 28 个地点；覆盖车厘子、樱桃、辣椒等农业地点，包含温度、降水、风速及田间作业/道路交通/冷链运输参考。保留既有演示时间基准 2026-09-21，新增记录日期为 2026-09-15—21。
3. **星闪**：沿用 V0.8 定位 DOM overlay 的方式，增加四角星形；事实和关联层、2D 和 3D 均可见，1.2 秒后移除。处理全球经度副本和三维可见半球，不把背面的点投到正面。单次最多六颗，避免高频事件堆积。
4. **通知**：真实 `data:ingested` 与现有流水 `stream:line` 接同一到达处理。右侧顶部通知与滚动卡片分离，新卡置顶并标记，通知约 4.15 秒后移除；事实层文案“新事实”，关联层“新本体”。更改筛选不伪装为新到达。重复 ID 入库被拒绝。
5. **关联地图**：初始化去除无效/自环/重复关系，并核对跨境物流支撑事实是否同时引用两端本体。585 条中隔离 44 条证据错配的跨境流向，541 条进入规范数据；本包没有额外结构无效/重复项。渲染再去除同坐标重线、分配地理走廊/端点预算，全球默认显示 73 条，10 种正负曲度，单条关系只渲染一个就近世界副本。背景线不拦截地图；聚焦关系仍可点击。湖南与事实层共用 `china`、边界、中心 `[111.73,27.54]`、zoom 9.08，投影坐标一致。
6. **动画**：首次访问每个 2D 层级/省份才执行入场，3D 全球每个图层仅首次入场。详情更新只更新焦点，不重建流动 series；浏览器核对开关弹窗前后图元及 animator 为同一实例。3D 更新保留关系相位。隐藏关联地图时暂停 ZRender 动画。

关于上轮“东南亚→红星”旧待办：原包存在把全国进口事实套到任意产区→指定市场的连线。本轮移除不具备双端证据的跨境流向，不为凑数量补造此类关系；有直接证据后通过入库边界补充。原始 `data/pkg/relations.json` 未覆盖，便于复核。

## 数据来源与复现

- [Open-Meteo 历史天气接口](https://open-meteo.com/en/docs/historical-weather-api)：公共气象再分析估计，不宣称为气象站实测或道路事故/运价实录。
- `data/pkg2/global-weather-source.json`：原始响应和请求 URL，未打包进页面。
- `data/pkg2/global-facts.json`：609 条规范补充记录，每条保留来源 URL、原日期、地点、洲、再分析数值和 `provenanceMeta`。`sourcePlugin=global-agri-enrichment`、`dataOrigin=public-reanalysis`、`dataMode=real`。
- 农作物语境和运输安排文字为编辑标签，不表示已证实的产量变化或物流事故。既有数据的 real/generated 标记不改写。
- `python3 tools/collect-global-agri.py` 优先使用原始响应缓存，生成补充包；构建包含整个补充包的内容指纹。

## 启动与检查

```sh
npm ci
npm run build
npm run test:all
# 事实和关联层可直接用浏览器打开 index.html，或运行 npm run serve
```

`test:all` 包含既有 PRD、全球重复地图、拖拽回归，以及 `test/intake-map-regression.mjs`：冷启动、真实入库去重、两层通知/星闪、3D 星闪、真实画布点击下钻、首次/再次访问、弹窗流动实例保持、六洲数据、性能与 390px 横向溢出检查。

Chromium 1440×900 本地采样：六个二维视角共 90 帧连续漫游，帧间隔 P95 约 33.3ms，最大约 83.4ms，最慢切换约 82ms。独立三层切换采样未记录到长任务。此为本机测量，不代替目标设备验收。拖拽回归 24 次 georoam，节点相对地图漂移 0px、图元替换 0 次；无页面异常。

自动证据保存在 `test/artifacts/llm291/`（git 忽略）：`report.json`、`fact-hunan.png`、`fact-intake.png`、`relation-world.png`、`relation-intake.png`。验收可用 `V03Fact.notifyNewest()`、`V03Relation.notifyNewest()` 触发可视到达反馈；实际新增入口为 `V03Data.ingest({facts,objects,relations})`，输入使用内部规范模型，新增 ID 才会触发入库事件。
