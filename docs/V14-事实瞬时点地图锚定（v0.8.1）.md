# V14 · 事实瞬时点地图锚定（V0.8.1）

## 症结

V0.8 已将持久事实点、密度点、影响圆和扩散波纹迁入同一个 ECharts `geo` 坐标系，但遗漏了底部接入流触发的“新事实瞬时闪点”。该闪点仍是 `factMapBox` 内的绝对定位 DOM 元素：创建时只调用一次 `convertToPixel()`，随后地图拖动或缩放时不会重新投影，因此在约 1 秒的生命周期内会停留在旧屏幕坐标，形成事实点与地图脱层的直接观感。

关联层没有该缺陷，因为节点和连线始终是 `coordinateSystem: 'geo'` 的 ECharts series，不存在地图外的覆盖层。

## 修复

- 删除 `.star-flash` DOM 图层和对应 CSS 动画。
- 新事实闪点改为 `freshFlash` `effectScatter` series，和 `mass`、`halo`、`ripple`、`facts` 共用唯一 `geo`。
- 瞬时点仍在 1.2 秒后删除，但在整个生命周期内由 ECharts 随地图平移、缩放和高 DPI 画布统一重投影。
- 保留 `V03Fact.flashIds()` 调试接口，但数据来源改为 geo series 的瞬时点队列。

## 回归口径

`test/v081-map-anchor.mjs` 不再只比较 `convertToPixel()` 理论结果，而是读取 ECharts 最终 Canvas 图元的全局坐标，与同一经纬度的 geo 投影逐点比较。覆盖：

1. DPR=2；
2. 20,000 个密度采样点；
3. 持久事实点、光晕、扩散波纹、新事实瞬时闪点；
4. 连续四轮拖动与滚轮缩放；
5. 关联层节点和连线作为对照组。

验收阈值为小于 0.25 CSS 像素；当前五类事实图层最大漂移均为 0。
