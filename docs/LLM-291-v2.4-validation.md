## 真实来源与边界

- **14,700 条历史气象记录**：30 个成功响应批次、2,100 个请求坐标，每点 2026-10-07—13 七天。其中湖南 740 坐标 / 5,180 条。原响应留在 `data/pkg2/v24-weather-raw/`，紧凑数据 `v24-weather.json`，收集工具 `tools/collect-v24-weather.py`。`v24-weather-places.json` 是请求计划，不把失败/未请求的坐标计作事实。模型实际网格经纬度与请求坐标分别保存；这是农业、交通与冷链天气参考，不是 2,100 个气象站，更不是交易或灾害实录。来源：[Open-Meteo 历史天气 API](https://open-meteo.com/en/docs/historical-weather-api)。
- **湖南/河南/山东业务地物**：公开 [Geofabrik 中国省级 OpenStreetMap 提取](https://download.geofabrik.de/asia/china.html)，经 pyosmium 提取命名的市场、果蔬店、农产品直销店、商超、批发店、果园/农场与仓储。保留原 OSM 类型、ID、标签、更新时间、原文 URL、ODbL 署名，见 `v24-osm-*-source.json`；同名同坐标地物去重。工具 `tools/collect-v24-osm-extract.py`。way 的坐标是参考中心，明确 approx，不当作建筑边界或精确门牌。目录资料不宣称实时营业、库存或成交量。
- **新增 1,200 个机场**：公开 [OurAirports 数据](https://ourairports.com/data/)，从 [datasets/airport-codes 快照](https://github.com/datasets/airport-codes/blob/master/data/airport-codes.csv) 中筛选尚未入库的大中型机场，保留中国条目并按国家轮询。原 CSV 与冻结选择分别在 `v24-airports-source.csv`、`v24-airports-selected.json`。不从机场存在推断农产品航线、货运资质或吞吐量。
- 新目录通过有证据的 **LOCATED_IN/位于** 连接行政归属，不伪造供应或交易飞线。原有 74 条有来源业务线、重点线/淡隐粒子与点击详情保留。行政归属未设置虚构城市坐标，不把归属线画成贸易路线。
- 自然本体到达改为 **36 个尚未注册的真实业务目录条目**，按当前可见视角走 `D.ingest` 入库、DOM 四角星、通知和新卡置顶；“新”指本页面新接入，不宣称市场刚开业。队列用完/网络失败时回放明确标注，不累加虚构数据。事实层继续真实当前天气入库；气象没有独立业务本体卡。
- 红星、酉阳、邵阳证据边界和外部图像/六个直连直播源延续 V2.3；不把本轮新零售设施推断为红星所属市场。图片只使用外部 URL，没有下载照片入仓。

## 性能与验证

独立坐标合并、多日事实共享静态地图边界命中缓存、业务对象过滤缓存、ECharts 批量绘点、不重复 resize 画布；列表首批 20/24 卡，滚动追加/展开有上限。新批次不重建已打开的搜索框和详情抽屉；弹窗不重放飞线入场。密集绘点仍须物理鼠标点击可打开事实/同坐标列表。

```sh
npm run build
npm run test:all
npm run test:v24
node test/v24-interactions.mjs
node test/v24-globe.mjs
node test/v23-interactions.mjs
```

`v24-delivery` 自然等待 32 秒载入及六视角星闪/新卡，不手动调用通知入口；核查十倍计数、独立坐标、无测量伪本体、卡片高度/照片 URL 去重、390px 无横向溢出与页面异常。`v24-interactions` 观察两层三视角切换/缩放长任务，并实际点击批量绘图模式中的事实点；`v23-interactions` 实点真实可见关系曲线和流动粒子核对关系 ID。`test:all` 覆盖全 UI、世界拖动副本、点位投影、入场动画实例、搜索与旧通知回归。临时服务和浏览器在前台调用完成前关闭。

本机 Chromium 1440×900 实测：自然载入 **32.076 秒**；中国 **18,553 条 / 4,939 坐标**，湖南 **6,312 条 / 1,432 坐标**。六个 2D 视角及两层 3D 地球均自然出现星闪、通知和新卡（事实为真实天气入库；本体为真实业务目录入库），页面异常 0；关联地球实际 600 个业务节点。旧四项回归与真实关系曲线/流动粒子点击通过；两层三视角与历史参考像素误差 <.01px，实际点击中国下钻湖南也保持最终坐标与 9.08 缩放。每面板照片 URL 无重复、无图卡片自然紧凑，390px 无横向溢出。

性能记录区分阶段：初次解析最大长任务约 **147ms**；32 秒批次展示最大 **63ms**，六视角自然到达附近最大 **75ms**；切为“全部时间”并生长期间曾有一次 **102ms** 任务。单独的完整载入后两层三视角切换/缩放用例未观察到 ≥50ms 长任务，批量散点中的真实鼠标点击成功打开相同事实 ID。保留上述初始化/时间生长峰值，不宣称所有任务都 <100ms，也不以复制世界数量冒充独立点或性能证据。
