## 2. 字段映射（SCHEMA §2 → 页面内部模型）

| 数据包字段 | 页面用法 |
| --- | --- |
| `factId` / `title` / `summary` | 卡片与详情主字段（`id` / `title` / `summary`） |
| `category`（10 个受控 L1） | 事实类型色系与图例（`D.CATS`，冷色，10 类） |
| `cardType` + `card.fields` | 六类卡片模板（news / policy / price / weather / video / market） |
| `taxonomy.l2 / l3` | 左侧菜单三级分类字典的叶子命中（取消一张即按二级 + 三级 id 精确收敛） |
| `geo.scopeLayer` | 空间层级（L1 全球 / L2 中国 / L3 省区），替代上一轮的视野盒推断 |
| `geo.geoPoint` | 地图星点坐标（`geoPoint=null` 的事实不上图） |
| `geo.regionPath` | 详情「行政区路径」与省区收敛（`CN-HN` → 湖南 281 条） |
| `credibility.band` | 可信度阈值（高 / 中 / 低），卡片 chip 与详情关键字段 |
| `severity` | 影响等级（≥70 高 / ≥40 中 / 其余低）、亮星分级、影响半径折算（80 + severity×3.2 km） |
| `entityIds` | 事实详情的「相关本体对象」与携带跳转 |
| `entityId / type / canonicalName / geo / attributes` | 关联层本体节点、本体详情、九类对象域（含 Person 14 个） |
| `relationId / relationType / nature / supportingFactIds` | 关联线、关系清单、关联详情；`verified` → 置信 ≥0.72，`inferred` → 0.55（待观察） |
| `geo/regions|ports|airports|nodes.geojson` | M5 / M6 图层标记（真实经纬度），点标记打开对应本体详情 |
| `stream.sequence.json` | 底部流水内容与顺序、批次、`star` 事件（`bright` / `dim`）驱动地图亮星 |
| `provenanceMeta.dataMode` / `sources.json` / `evidence.json` | 仅内部：`provSummary()` 与详情证据区（真实记录显示来源 + 原文摘录 + 外链；生成记录显示锚点登记，不冒充来源） |

**展示文案净化**：数据包内部允许出现「示例/样例」等登记用语（如「抖音农产品直播（示例链接）」）。
页面指令 G6 要求普通 UI 不出现这类字样，因此适配层对**渲染字段**做了净化（`cleanText`），
`data/pkg/*.json` 原始内容保持原样，便于验收复核。

## 4. 视频 / 直播处理（按数据包 `embeddable` 字段）

| `embeddable` | 页面行为 |
| --- | --- |
| `yes`（已验证可嵌入） | 渲染播放器；快捷键 M4 开启时挂载 `iframe`（真实播放），关闭时卸载并显示暂停层 |
| `no` / `unknown`（当前 10 条全部如此） | **静态卡片降级**：封面 + 频道 + 降级原因 + 「打开原始视频源」外链；不挂载任何 iframe / video 元素 |

当前数据包内 10 条视频事实均为 `unknown`（9）或 `no`（1），因此页面不播放任何外链视频，
离线属性保持（测试断言：视频机制验证之前外部请求数 = 0）。机制验证见 `test/v03.mjs` 的 M4 用例
（`V03Fact.forceEmbeddable()` 临时把一条事实标记为已验证 → 播放器出现且 M4 真实控制播放/暂停）。

## 5. 默认口径与生成记录再平衡（口径修正）

权威指令要求 **M7 默认近 7 天、M8 默认高可信、M9 默认高影响**。
数据包原样使用时，默认口径下全球视野只剩 **0～2 个点**（生成的 771 条事实里 `credibility.band=high` 为 0 条，
且联合窗口命中为 0）——密度与包设计（全球 342）冲突。按指令「在**不改变真实记录**的前提下调整 **generated**
数据的日期、可信度、影响等级分布」，处理如下：

**真实公开记录（90 条）零改动**：日期 / 可信度 / 影响等级保持数据包原值（测试逐条比对 `data/pkg/facts.json`，
`realUnchanged = 90/90`）。默认口径下的密度由生成记录承担。

**生成记录（771 条）确定性再平衡**（`src/v03/pkg-adapter.js` `rebalanceGenerated`，同一输入永远同一输出）：

| 档位 | 组内排名 | 日期 | 可信度 | severity（→ 影响等级） |
| --- | --- | --- | --- | --- |
| tier1 | 前 25% | 近 7 天内 | 高 | 72–96（高影响） |
| tier2 | 次 25% | 一半 7 天内 / 一半 8–30 天 | 高 60% / 中 40% | 45–69（中影响） |
| tier3 | 再次 25% | 8–30 天 | 中（少量高/低） | 40–64（中影响） |
| tier4 | 其余 | 31–180 天 | 中 2/3 / 低 1/3 | 20–39（低影响） |

分档在「**空间层 + 地理分组**（L1/L2 按国家、L3 按省）」内进行，保证每个区域都有默认口径代表点。
组内排序沿用原始 severity 与日期，因此相对重要度不变，只改档位分布。

实测结果：

| 口径 | L1 全球 | L2 中国 | L3 湖南 | 区域覆盖 |
| --- | --- | --- | --- | --- |
| 默认（7 天 + 高可信 + 高影响） | **77 点** | 42 点 | 68 点 | **23 个地理分组**（东南亚 / 南美 / 北美 / 南亚 / 大洋洲 / 非洲 / 欧洲全覆盖） |
| 切到「全部 / 不限 / 不限」 | **342 条（落图 339 点）** | 175 | 281 | 与 `stats.json.densityPlan` 一致 |

tier 分布：tier1 202 / tier2 189 / tier3 197 / tier4 183（合计 771）；`data/pkg` 原始 JSON 一字未改，
再平衡只发生在适配层，`V03_DEBUG.rebalanceSummary()` 可查看规则、原文对照与默认口径统计。
