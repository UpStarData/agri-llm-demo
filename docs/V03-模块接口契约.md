# V0.3 三层 Demo · 模块接口契约（实现冻结）

三个一级 TAB（事实层 / 关联层 / 推演层）共享同一页面骨架；报告属于推演层，不是第四个 TAB。
本文件是模块间的唯一接口约定，改接口必须先改本文件。

## 1. 状态：`window.V03Store`

```js
V03Store.state = {
  tab: 'fact' | 'relation' | 'sim',
  time: '7d' | '30d' | '90d' | 'all',   // 相对 2026-09-20（V03Data.TODAY，V03Data.inWindow(date, win)）
  cat: 'all' | 'policy' | 'price' | 'weather' | 'logistics' | 'trade',   // 事实层分类
  cred: 'all' | 'high' | 'mid' | 'low',
  infl: 'all' | 'high' | 'mid' | 'low',
  q: '',                                 // 搜索串
  rail: true,                            // 左侧分类栏是否展开
  panels: { cards: true, stream: true }, // 事实卡片区 / 底部流水区显隐
  geo: { level: 'L1'|'L2'|'L3', focus: null | '湖南' },   // 空间下钻
  factId: null,                          // 打开的事实详情
  carry: [],                             // 携带进入关联层/推演层的事实 id
  rel: { view: 'graph'|'geo', domain: 'all'|<九类对象域>, sel: null|对象/关系 id, kind: 'object'|'relation', focusFact: null },
  sim: { scenario: 'S1'|'S2'|'S3', stage: 0..6, status: 'idle'|'running'|'paused'|'done'|'failed',
         round: 0, rounds: 0, paused: false, replay: false, offline: false,
         sidecar: 'ok'|'degraded'|'offline'|'error', speed: 1, seedIds: [], autoRun: false }
}
```

- 写状态：`V03Store.set({...})`（顶层键浅合并；`panels` / `rel` / `sim` / `geo` 支持一层合并）。每次调用都会广播给所有已挂载层。
- 订阅：`V03Store.on((state, changedKeys) => {...})`（shell 已订阅并转发给各层 `update()`，层内不要重复订阅）。
- 事件：`V03Store.emit(name, payload)` / `V03Store.onEvent(name, fn)`。事件名：`toast`、`jump`（层间跳转）。

## 2. 数据：`window.V03Data`（`src/v03/data.js` 已冻结）

- `CATS` 五类事实分类：`{policy, price, weather, logistics, trade}` → `{n, c}`。
- `DOMAINS` 九类对象域：`market/company/base/variety/agency/region/person/metric/facility` → `{id, n, geo, c}`。
- `FACTS[]`：`{id, cat, date, level:'global'|'china'|'province', region, short, lat, lng, cred, impact, radius, media:'image'|'video'|'live'|'text', mediaNote, title, summary, evidence:[{t,k,q}], objects:[objId], relations:[relId]}`
- `OBJECTS[]`：`{id, domain, name, sub, lat, lng, geo, props:[[k,v]]}`；`geo:false` 的对象**不得**出现在任何地图点图层。
- `RELATIONS[]`：`{id, from, to, type, strength, confidence, formed, changedBy(事实 id), factIds[], note}`
- 查询助手：`factById` / `objById` / `relById` / `domain(id)` / `factsOfObject(objId)` / `factsOfRelation(relId)` / `relationsOf(objId)` / `factsFor(ids)` / `inWindow(date, win)`。
- 底部流水（由 shell 统一渲染，层内不要自己画）：`STREAM.fact[]`、`STREAM.relation[]`，元素为 `[kind, text, factId|null]`。

## 3. 层模块接口

```js
window.V03Fact     = { mount(rootEl), update() };
window.V03Relation = { mount(rootEl), update() };
window.V03Sim      = { mount(rootEl), update() };
```

- shell 先注入 `#layer-fact` / `#layer-relation` / `#layer-sim`，对每个层各调用一次 `mount(document.getElementById('layer-xxx'))`，之后每次状态变化调用该层 `update()`。
- 层只允许操作自己 root 内的 DOM；**不得**改其他层的 DOM，不得改 `index.html`、`build.mjs`、`src/v03/app.js`、`src/v03/data.js`、`src/v03/store.js`、`src/v03/shell.html`、`src/v03/app.css`。
- 层自己拥有的文件：关系层 `src/v03/relation.js` + `src/v03/relation.css`；推演层 `src/v03/data-sim.js` + `src/v03/sim.js` + `src/v03/sim.css`。
- 层必须自行处理“root 为空”（未激活 TAB 时 root 可能为 `hidden`）；`update()` 必须幂等，反复调用不得堆叠 DOM 或丢状态。
- 交互一律写回 `V03Store.set()`（例：点事实点 → `set({factId})`；切视图 → `set({rel:{view:'geo'}})`；推进一轮 → `set({sim:{round, status}})`）。禁止“只换文案不动状态”的假按钮。
- 跳转：`V03Store.set({tab:'fact', factId:id})` 由 shell 负责切换 TAB 并打开事实详情；层内不要自己切 TAB 容器。

## 4. 视觉与命名约定

- 只用浅色 AgriLink 语言：背景 `#f4f6fa`、卡片 `#fff` 白底、`1px solid rgba(15,23,42,.10)` 描边、圆角 10–14px、主色 `#1d4ed8`、强调绿 `#16a34a`、警告 `#b45309`。禁止暗色仪表盘。
- 层内 CSS 全部写在自有 CSS 文件里，类名必须带前缀（关系层 `.rel-*`，推演层 `.sim-*`），避免与 shell/事实层冲突。
- 数字用 `font-variant-numeric: tabular-nums`；每个面板卡片标题 12–13px 字重 600；正文 13–14px。
- 每个可交互元素都要能被文案理解（不用含义不明的图标）；键盘可达（`<button>` 优先）。
- 任何样例数据都要显式标注「示意数据 · 待标定」；不得声称真实后端运行。

## 5. 构建与自检

- 构建：`npm run build`（shell `src/v03/shell.html` + `app.css` + 各层 CSS + `v03/*.js` 内联为单文件 `index.html`，离线可用）。
- 自检（只允许跑语法检查，不要跑 build，避免与主线程互相覆盖产物）：`node --check src/v03/xxx.js`。
- 地图：shell 启动时已注册 `echarts.registerMap('china', window.__CHINA_GEO)` 与 `echarts.registerMap('world110', window.__WORLD110)`；层内直接用 `echarts.init(本地容器)`，不要重复注册。
