# V0.8.13 · 循环全球地图与展示配色

## 地图逻辑

- 全球二维视角以中国附近为画面中心，美洲在右。世界图形在经度上连续重复，拖动超过一周时按 360° 归一化，所以左右拖动都能不断循环。事实层、关联层的地图、点和线使用同一套显示坐标；源数据和 3D 地球仍保留原始经纬度。
- 国家与省区的接壤关系由原始边界顶点建立。共享至少两个边界顶点即视为相邻，按图着色分配色块；两个接壤区域不用同一色。颜色仅帮助辨识地理区域，不表示任何风险、饥饿程度或实测指标。
