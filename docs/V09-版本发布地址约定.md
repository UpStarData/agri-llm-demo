# 版本发布地址约定（每次发版换地址）

> 产品要求：**每次发版都换一个带版本号的新地址**，旧版本地址保留可回溯（便于对比与回看）。

## 地址规则

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 公网（GitHub Pages） | 仓库名 = `agri-llm-demo-<版本>`，地址 = `https://upstardata.github.io/agri-llm-demo-<版本>/` | `…/agri-llm-demo-v0.6/` |
| 局域网（郭慧这台机） | `http://192.168.1.83:3101/<版本>/`，根路径为版本目录页 | `http://192.168.1.83:3101/v0.6/` |

## 发版步骤（下次照做）

```bash
cd <repo> && node build.mjs && node test/v03.mjs          # 构建 + 自检（须全绿）
# 公网：新仓库发布，不动旧版本
git worktree add --detach <临时目录> HEAD
cd <临时目录> && git checkout --orphan pub<版本> && git rm -r --cached . -q
cp <repo>/index.html <repo>/build-meta.json . && 写 PUBLISH.md
git add -A && git commit -m "publish(VX.Y): …"
gh repo create UpStarData/agri-llm-demo-vX.Y --public
git push -f https://github.com/UpStarData/agri-llm-demo-vX.Y.git pub<版本>:main
gh api -X POST repos/UpStarData/agri-llm-demo-vX.Y/pages -f 'source[branch]=main' -f 'source[path]=/'
# 局域网：版本子目录 + 根目录版本索引
mkdir -p <lan>/vX.Y && cp index.html build-meta.json <lan>/vX.Y/ && 更新 <lan>/index.html 列表
# 最后：实际访问两个新地址核对指纹与功能（不改旧地址）
```

## 回滚 / 下线单个版本

```bash
gh repo delete UpStarData/agri-llm-demo-vX.Y          # 公网整站下线
gh api -X DELETE repos/UpStarData/agri-llm-demo-vX.Y/pages
rm -rf <lan>/vX.Y                                     # 局域网版本目录
```
