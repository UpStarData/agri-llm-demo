## V0.8.10 色彩与地图动效规范

本版用于演示和评审。默认深色画面以深海蓝作为底色，让区域、事实点和关系线形成三级视觉层次；浅色模式保留相同的色彩语义。

| 元素 | 深色值 | 用途 |
| --- | --- | --- |
| 页面底色 | `#061923` | 大屏底色 |
| 海洋底色 | `#041e2b` | 2D 地图 |
| 面板 | `#142630` | 信息卡片 |
| 主文字 | `#f1f8f7` | 标题与关键数值 |
| 强调青 | `#67d4e5` | 操作焦点 |
| 绿 / 琥珀 / 紫 / 珊瑚 | `#9bd483` / `#f0bf75` / `#b6a7e5` / `#f09282` | 类型区分 |

国家和省区采用七个低饱和色：`#205467`、`#235b57`、`#3c5963`、`#535c4b`、`#625748`、`#36516c`、`#3f625f`。颜色由地区名称稳定分配，只用于让相邻区域易于辨认，不代表产量、风险或其他统计指标。全国视角使用同一规则给省区配色；3D 地球与 2D 世界地图一致。

3D 地球的动态弧线来自演示数据中有地理坐标、可信度不低于 0.6 的关系记录。按关系类型使用青、琥珀、绿、珊瑚、紫五种颜色；线宽约 1–2.4 px，按关系强度变化。每种颜色最多展示四条，总数最多十六条，亮段沿弧线移动，避免密集遮挡。弧线表示“关系连接”示意，不应被解读为实际物流轨迹或实时监测。页面直接标注“关联层演示数据”。

本版演示数据的时间截面为 2026-09-21。页面显示该日期，不把旧记录伪装为当日实时事实。3840×2160 布局扩大基础字号、工具条和右侧卡片区；实际大屏验收仍应使用目标屏幕距离和硬件现场检查。
