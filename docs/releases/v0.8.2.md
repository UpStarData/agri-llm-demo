# AgriLink V0.8.2

LLM-291 地图交互实测补丁。上一版宣称的“零漂移”只说明帧内坐标一致，未检验连续交互时的卡顿及国界外点位，因此结论不充分。

本版修复两处可复现问题：

1. 中国视角的事实层只按经纬度矩形筛选，矩形包含邻国区域。实际发布版在中国地图外画出了 4 个事实点。现在上图事实与新事实瞬时闪点均须通过 GeoJSON 面内校验。相同交互后，中国视角从 141 个事实点中剔除 4 个国界外点，剩余 137 个，国界外为 0。
2. 连续拖动/缩放时，`georoam` 每次事件重入 `setOption()`，且 2 万个普通 scatter 图元和逐点全 GeoJSON 包含判断占用主线程。现在地图事件停手后才同步状态，密度层使用 ECharts 大数据绘制，采样预算按视角调整为 5000/4000/3000；地理面边界索引减少点在面内判定开销。概览体量口径未变，采样数在提示中如实显示。

验证采用与 V0.8.1 相同的 1440×900、DPR=2、三轮连续拖动和滚轮缩放场景。V0.8.1 公网版：8 秒内采样到 62 帧，95% 帧间隔约 272ms，最长约 446ms。修复后本地同场景：采样到 388 帧，95% 帧间隔约 35ms，最长约 121ms；五类点图元与地图投影最大偏差小于 0.001 CSS 像素。该数据是本机单次交互对比，不能代表所有设备达到固定帧率。

自动回归：`npm test` 69/69、`npm run test:v08` 6/6、`npm run test:v081` 6/6。现场录屏/截图可用 `node test/probe-roam-frames.mjs <URL> --video --screenshot` 复现。
