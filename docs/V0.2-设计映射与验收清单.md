## 六、可操作主路径（第一版要求）

`总览（事实层地图） → 事实详情 / 证据 → 携带事实进入关联层 → 图谱或地理关联 → 关系详情与回溯 → 加入推演种子 → 推演配置与七阶段 → 轮次过程 → 报告与引用 → 返回对应事实/轮次`

- 测试脚本按这条路径逐步点击并断言状态（`test/v03.mjs`，56 项）。
- 每个新增交互都写回 `window.V03Store.state`，测试读状态判定，不以文案变化为准。
