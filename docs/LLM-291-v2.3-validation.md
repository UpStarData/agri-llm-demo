# LLM-291 V2.3：全球覆盖、自然到达和媒体接入

对应 2026-10-15 的 11 项追加反馈。交付目标是项目 Pages 的 `/v2.3/`、`/latest/` 和版本目录，并由交付验收智能体在发布后独立验收。

## 需求与实现

| 反馈 | 实现与证据入口 |
| --- | --- |
| 1 数据加倍、40 秒内分批 | 基础事实从 1543 增至 **3377**（1820 条真实气象再分析、8 条红星报道、6 个直连频道）。`V03Feed` 先展示约 600 条，再按地理网格轮询、每秒显示一批，32 秒完成；总数与已显示数分开。原始记录随单文件下载，分批的是地图/筛选展示，不伪装成后端流式下载。 |
| 2 俄罗斯、加拿大、中国各省，两层都有 | 新增 260 个真实行政/机场参考点：俄罗斯 44、加拿大 23、中国 58；气象每日各 7 条，分别 308、161、406 条。覆盖 138 个国家/地区。关联层有相应气象本体及行政归属关系；节点按空间网格抽样，避免热门节点挤掉稀疏地区。位置为城市/行政代表点，不冒充农场、气象站或工程边界。 |
| 3–5 新事实/本体自然亮星 | 复用 V0.8 的 14px 径向亮心、`.9s starFlash` DOM 效果，1 秒移除；删除关联层旧 `relFresh` 扩张圆。定时器在每次完成后随机等待 7.5–12 秒，请求当前视角一个参考点的真实当前气象，新事实与新气象记录本体走 `data:ingested`；重复 ID 不重复入库。失败或重复时明确标“事实接入回放 / 本体接入回放”，不增加事实数量。两层全球、中国、湖南及地球正面均按当前可见位置定位；背面不投到正面。右侧通知、新卡置顶与星同步。 |
| 6 淡隐飞线及聚焦 | 大部分底线透明度 .025，仅粒子明显；重点线 .28，选中本体相邻线 .9，其余线 .018。底线和流动 series 静默，页面自行命中可见粒子/可见曲线；空白地图仍可下钻。弹窗不重建流动动画。3D 同样区分重点和焦点，支持点流动粒子/可见线看关系。 |
| 7 紧急关系点击 | 原问题由静默背景线和粒子不能触发 ECharts 点击引起。使用真实画布 pointerdown/click、图元屏幕坐标命中；优先记录按下时的粒子，避免它在抬手前移动到另一条线。拖动超过 5px 不误开详情。回归覆盖可见曲线中段物理鼠标点击及真实粒子命中，检查真实关系 ID 和抽屉。 |
| 8 红星业务数据 | 8 条有原报道日期的长期项目资料、5 个本体、10 条关系；包含红星全球农批中心、酉阳共建项目、邵阳县金盆村产销合作、花垣辣椒合作、泰国榴莲/智利车厘子。国别流入线只在证据同时包含两端本体时保留，不补造逐段物流线路。 |
| 9/11 图片 | 移除旧伪缩略图。部分卡片一张外部原文/Commons 照片，事实、本体和关系详情均有一张照片或视频封面。找不到对应现场照片时明确标“主题资料图”；详情有来源、作者和许可。图片仅保存 URL，不在仓库打包或下载图片文件。懒加载、异步解码、失败降级不影响地图。 |
| 10 直播 | 从附件筛选公共 HTTPS 播放源，检查主/子播放清单、CORS、真实媒体分片，再做 Chromium 实际解码。6 个可播放频道接入 `<video>`/hls.js，不嵌整站网页；全页最多一个解码器，离开视口销毁，失败可显式重试。播放器与已存在卡片不会被每秒数据批次重建。 |

## 原始来源及边界

- 气象：`data/pkg2/v23-weather-source.json` 保存真实响应；`v23-weather.json` 是规范数据。日期 **2026-10-07—13**，页面快照基准 **2026-10-15**，原包日期不改。模型再分析是农业作业/运输安排参考，不能当作灾害、交通事故或运价实录。[Open-Meteo 文档](https://open-meteo.com/en/docs/historical-weather-api)。
- 酉阳：农业农村信息网[签约报道](https://www.agri.cn/zx/xxlb/zq/202507/t20250704_8746564.htm)、县政府[招商中心揭牌](https://youyang.gov.cn/sy_236/yyyw/202602/t20260212_15439651.html)、[阶段建设进度及原图](https://youyang.gov.cn/ysyy/yshd/202608/t20260810_15911759.html)、人民网[一期启用](https://cq.people.com.cn/n2/2026/0924/c367650-41707128.html)。2026-08-10 的 95% 建设进度保留历史时点，不称为今天的施工状态。
- 邵阳：[金盆村产销合作](https://sy.rednet.cn/content/646842/58/14180519.html)。目前证据支持基地与红星销售合作，**不支持“红星全资邵阳大市场”**，页面不作该断言。
- 辣椒：[花垣合作报道](https://cs.rednet.cn/m/content/2022/07/26/11561574.html)，文章发表于 2022 年、回顾 2021 年情况，文案保留两者区别。
- 进口水果：[红星市场泰国榴莲、智利车厘子](https://hnny.rednet.cn/content/646745/53/12249954.html)、[进口交易区冷链到货](https://hn.people.com.cn/n2/2022/0129/c356884-35119132.html)。
- `v23-project-geocodes.json` 留存查询结果。错误匹配到合肥的“酉阳板溪工业园”结果被拒绝；酉阳用县代表点、金盆村用邵阳县代表点、红星全球农批中心用邻近同名公交站参考点，详情均保留近似精度。
- `v23-media.json` 留存原图 URL、来源和署名；`collect-v23-media.py` 只取元数据与新闻 HTML，不下载图片。农作物图片来自 Wikimedia Commons 可核对的文件页，项目图来自原报道。
- 直播附件中的旧测试结果不直接当作现状。`v23-stream-validation.json` 留存本轮清单/分片探测；`v23-browser-media-validation.json` 留存浏览器真实出画证据。**FarmodaTV、MRTV Farmer、NatureTime、Agrotendencia TV、Agro TV、WildEarth** 实际出画；Stingray 虽通过清单探测，但浏览器解码失败，未进入页面。频道是公开农业/自然节目，不能冒充红星或指定港口的现场摄像头。第三方源可随时变化。

## 性能与验证

地图对同坐标多日事实合并为一个交互点，保留所有事实 ID、卡片与计数；ECharts 数据批次合并更新当前 geo，不卡断已有流动动画。右侧事实首批 20 张、滚动加载；关联卡片 24 张起、展开最多 120 张；地图点数量与原始事实数量不混淆。

```sh
npm run build
npm run test:all
npm run test:v23
```

`test/v23-delivery.mjs` 不调用手动通知入口：观察自然 32 秒批次与随机到达，在两层各三个视角等待真实星闪、通知，再检查粒子对应关系和详情图片/直连直播。`test/v23-interactions.mjs` 用实际 ECharts 图元和画布事件回归紧急点击。`test/v23-media.mjs` 用浏览器逐一实际解码，检查画面宽度/播放进度、零事实网页 iframe、最多一个解码器。测试临时 HTTP 服务和 Chromium 都在同一前台调用结束前关闭。

旧湖南影响圆回归采用“全部时间”并等待原有时间切换生长动画完成，因为新快照日距上一轮数据已 24 天，不把过期数据改成今日数据来满足旧断言。其他地图投影、下钻、拖动、动画实例保留测试继续执行。

本机实测（最终功能构建）：基础 **3377** 条；自然分批 **32.053 秒**完成；初次解析最长长任务 **122ms**，后续载入/自然气象到达最长 **79ms**。六个 2D 视角本轮均出现真实气象入库与新记录本体通知，无手动调用通知入口。默认全球 74 条关系，67 条底线淡隐、7 条保留细线；实际粒子命中打开相同关系 ID 的详情。MRTV Farmer 画面宽 720、播放时间前进、解码器 1、网页 iframe 0。外部项目详情图片实际加载成功，无页面异常。

旧回归：24 次真实 georoam 事件、点位偏移 0px、图元替换 0；湖南事实与关联地图的 map/center/zoom/长沙像素位置一致；首次进入和返回均保持影响圆直径 ≤88px、像素间距 ≥40px。1440/390 宽度无横向溢出。视频六源实测画面宽度分别为 1920/720/426/1920/640/640，均有播放进度。
