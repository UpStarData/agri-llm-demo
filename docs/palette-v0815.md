# V0.8.15 · 事实层与关联层整页配色

这次按页面统一调整，不把地图色块当作一套独立配色。事实层和关联层共用两组颜色令牌：地图海面、行政区域和边界，页面背景、顶栏、面板、卡片，按钮、地图控件与图标状态，以及事实点和关系节点。地图类别色仅区分相邻地理区域，不表示统计等级。

| 用途 | 配色 1 · 清爽地图 | 配色 2 · 户外地图 |
| --- | --- | --- |
| 海面 | `#b8cee0` | `#78c4df` |
| 陆地基底 | `#f1efe8` | `#e9ecd9` |
| 页面底 | `#edf2f5` | `#eaf1e9` |
| 卡片和浮层 | `#ffffff` | `#fffdf8` |
| 按钮／可操作元素 | `#236bad` | `#355fd0` |
| 事实点轮廓 | `#236bad` | `#315fb8` |

视觉参照来自用户提供的 Felt 地图截图（浅蓝海面、奶油色陆地、轻量白色浮层）和 Mapbox Studio 中 Outdoors 风格的截图（青蓝水面、绿色植被与象牙色地表、饱和蓝色交互元素）。本原型使用离线行政边界数据，没有道路、地形或植被分层，因此保留行政区接壤异色逻辑，以淡绿色、奶油色和灰蓝色近邻区域表达，而不声称复刻 Mapbox 或 Felt 的地图样式或使用其地图素材、服务或令牌。

参考地址：[Felt 示例地图](https://felt.com/map/Untitled-Map-pkeWM703Q5OqcQqeN4MtHC?loc=41.68,109.51,2.5z)；[Mapbox Studio](https://console.mapbox.com/studio/)。来源为用户在 issue 提供的六张截图；本版色值经过原型适配，并不是从网站中逐项提取的官方色号。

验证：事实层和关联层分别在两种配色下查看整页截图；地图在 390、1440、3840 像素视口下仍以中国为中心；全球地图连续拖动、相邻国家异色和事实点／本体点同步的原有检查均通过。未解决的地图逐帧点位短暂漂移仍单独跟踪。
