市县边界：DataV行政区公开GeoJSON，`https://geo.datav.aliyun.com/areas_v3/bound/430000_full.json`及14市州的同格式子级文件；136个市州/县区几何，冻结于`v25-hunan-areas.json`。茶陵/炎陵项目使用该区划来源的县域代表点，明确非工厂/果园地块精确坐标；盛康企业无可靠具体坐标，留在卡片/图谱。酉阳共建、金盆村产销合作的旧证据边界不变。

新增报道与本体支持事实双向索引同步，既有集团及商品的详情也能查到新资料；实时入库同样补齐双向引用。

原数据包包含既有生成演示基线；本轮没有将其改标为真实。新增红星资料与设施目录有独立原文来源，气象为模型记录，不伪称现场观测或灾害。
