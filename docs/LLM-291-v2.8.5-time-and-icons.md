# V2.8.5 · 时间筛选会消失、2D 全球上色、图层图标改矢量

用户 2026-10-17 三条反馈。

## ① 时间筛选：点会消失，不同时间窗效果不同

**根因**：`filter.js` 里时间过滤写成 `(f.persistent || D.inWindow(f.date, s.time))`，而 51,872/55,223（**94%**）
的事实被标成 archive/persistent，因此切换时间窗几乎不改变数据（改前：today 51,861 / 30d 54,556 / all 55,209）。
叠加的"生长"动画只做「按比例少画几个点」，从不做「已有点退场」，所以只看到缓慢出现。

**改法**：
1. 时间窗对所有事实生效（档案仍保留原始发布日期，只是按窗口过滤）。实测各窗口事实数：
   `today 3,716 · 7d 5,526 · 30d 7,797 · 180d 15,263 · 365d 20,271 · all 55,209`，
   地图绘制点：`234 · 357 · 1,602 · 5,895 · 7,062 · 9,600`——切换窗口时数据确实不同、点会减少。
2. **退场动画**：切换时间范围时，上一帧的点作为 `factExit` 图层保留并淡出（实测切换到「今天」时
   4,000 个旧点从透明度 0.54 线性降到 0.001，约 2.9 秒），新点同时按新窗口生长。
3. **不同时间窗的铺点节奏不同**：today 1.5s、7d 1.8s、30d 2.2s、180d 2.7s、365d 2.9s、all 3.2s。

## ② 2D 全球也按分类上色

**根因**：`facts` 系列开着 ECharts 的 `large` 模式（`largeThreshold:1500`）。large 模式**忽略逐点 itemStyle**，
全球视角 9,600 点全部被画成同一个默认色；2D 中国 1,376 点未触发 large，所以那里颜色是对的——
正好对应用户"全国上了、全球没上"的观察。

**改法**：关闭 large（`large:false`），世界取点维持 2,600 个坐标组（7,800 点）以控制开销。
实测 2D 全球 7,800 点、**7 种一级分类色全部出现**，逐点等于其分类色。

**代价（如实）**：全球视野切换（一次用户操作）从 277ms 涨到 **364ms**，单帧最大 400ms，帧间 p95 仍 50ms。
`intake-map-regression` 的预算据此从 320/420 调到 420/460，并把依据写在测试注释里。

## ③ 叠加数据图层图标：emoji 字形 → 内联 SVG

原来 5 个叠加图层（产区/港口/机场/农贸市场/地缘风险区）是把 emoji 当**文字**画在 label 上，
不同系统字体渲染不一致、也不是矢量。现改为**内联 SVG（data URI）**：白底圆 + 图层色实心图标，
透明底、缩放不糊、随图层配色；左侧菜单"叠加数据图层"的 5 个图例用同一套 SVG（不再有 emoji 字形）。

## 验证（test/v285-factlayer.mjs）

- 全球：`large=false`、7,800 点、7 种分类色、逐点色 ∈ 主题色板；
- 时间窗：事实数与绘制点数随窗口收窄严格递减，`today` 仍有 3,716 条 / 234 点（不为空）；
- 退场：切换瞬间出现 `factExit` 图层（4,000 点），透明度随时间下降直到消失；
- 图标：5 个叠加系列 symbol 均为 `image://data:image/svg+xml`，菜单 5 个内联 SVG、**0 个 emoji 字形**。
