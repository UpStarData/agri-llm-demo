# V2.8.7 · 叠加图层图标改回纯 emoji（且真正透明）

用户 2026-10-17：「叠加数据图层的 icon，我希望还是纯的 emoji 表情包，你找的不符合我的要求，而且是支持透明格式」。

**我上一版理解错了**：V2.8.5 我把自己手画的 SVG 图形换了上去，用户要的是**真的 emoji 表情本身**，
并且要**透明**。

## 「透明」在这里指什么

图标区域里**除了 emoji 字形自己的像素，其余全部是底图**——没有白色圆底、没有底色块、没有描边、
没有裁切方块。原来（V2.8.4 及之前）是把 emoji 画在 label 上，但底下还画了一个 `rgba(255,255,255,.6)`
的白色圆点，看起来就是一个白点贴纸，所以"不透明"。

## 改法

- 叠加图层只用 **emoji 字形**：`🌾 产区（基地）· ⚓ 港口 · ✈️ 机场 · 🏪 农贸市场 · ⚠️ 地缘风险区`；
- 承载的散点符号设为**全透明填充**（`itemStyle.color: 'transparent'`，`borderWidth: 0`），
  不画白圆、不画描边；**不设 `opacity: 0`**——那会把 label 一起隐藏（踩过这个坑：emoji 会整个消失）；
- label 显式 `backgroundColor: 'transparent'`、`padding: 0`、`textBorderWidth: 0`，不留任何底色；
- 左侧菜单"叠加数据图层"图例同步改回 emoji（`🏪` 与地图上的农贸市场图标统一，此前菜单是 🏪、地图是 🛒）。

## 验证

- 渲染层：画布显示列表里 **75 个 emoji 字形**（🌾 ⚓ ✈️ 🏪），符号本身 `color = transparent`、
  label `backgroundColor = transparent`；菜单 5 个 emoji、**0 个 SVG**。
- 像素级：取一个机场图标的屏幕位置，在其周围 9px 的 8 个方向采样——得到 4 个地图像素
  `rgb(207,233,189)`、4 个画布外像素 `rgb(0,0,0)`，**没有近白像素**（若还有白圆底会采到接近 255 的值）。
- 截图：`test/artifacts/v285/icon-crop.png`（地图上的 emoji 图标）与 `menu-icons.png`（菜单图例）。

## 一点说明

emoji 由系统字体渲染（macOS 上是 Apple Color Emoji），所以透明与形状都跟系统一致。
如果哪天要求**跨系统完全一致的 emoji 外观**，那才需要把 emoji 做成内嵌 PNG/SVG 资源
（一套图标 ~几十 KB，内联进单文件），代价是文件变大；当前按"纯 emoji + 系统渲染"实现。
