## 三、已知限制

1. **直播播放需 http(s) 打开**：公开直播源的播放器帧带 `frame-ancestors`，在 `file://` 下会被浏览器拦截（本轮已按静态卡片降级处理，避免黑屏与控制台报错）。本地看视频请 `npm run serve` 后访问 `http://127.0.0.1:4173`。
2. **默认口径下视频事实多为中可信**：默认筛选为「近 7 天 + 高可信 + 高影响」，视频/直播事实多为中可信，需把可信度切到「中」或「不限」才出现在卡片流中（截图取证即在放宽口径下拍摄）。
3. 关联层「环境与事件」对象域当前 0 个对象（数据未注册该域实体，界面按空域呈现）。
4. 窄屏（390px）本轮仅做可用性自检，未交付窄屏截图。
5. 未发布线上版本；原站与 `agri-llm-demo-v04` 均未改动。
