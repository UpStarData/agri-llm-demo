# V2.8.6 · 首次切换时间窗也淡出（验收边界返修）

验收在 V2.8.5 的复验里发现一个边界：**会话内第一次切换时间范围时没有退场层**，旧点是瞬时消失的；
从第二次切换起才正常淡出。

## 根因

`fact.js` 的退场判定写成 `const sameView = exitLevel === st.geo.level;`，而 `exitLevel` 初始为 `null`，
首次切换必然 `sameView === false` → `exitPoints = []` → 没有退场层。

## 修法（一行判定）

`const sameView = exitLevel === null || exitLevel === st.geo.level;`

即：首次切换时只要上一帧有点集（`lastPaint`），照常取退场点；跨层级切换（L1↔L2↔L3）仍不混用
上一层的点，避免异层错位。

## 验证

`test/v285-factlayer.mjs` 新增「会话内第一次切窗」断言：冷启动后第一次从「全部时间」切到「30d」，
必须出现 `factExit` 层且点数 > 100。实测：**4,000 个旧点，透明度 0.72 → 0.53 → 0.37 → 0.25** 递减淡出，
同时新窗口的点生长进场（before drawn 7,800）。

`test:all`、`v284-colors`、`v28-delivery` 全部通过。
