# V0.3 与基线 AgriLink（46be371）的 1440px 对照与组件复用说明

对照对象：基线 `UpStarData/agri-llm-demo@46be371`（线上 `https://upstardata.github.io/agri-llm-demo/`）↔ V0.3 三层 Demo（分支 `llm-270/v03-three-layer`）。
对照口径：同一 1440×900 视口、同一 `file://` 离线加载方式、同一台机器连续截图；基线侧的 `index.html` 直接取自 `git show 46be371:index.html`，不做任何改字句。

## 如何复现

```bash
npm run build          # 构建新的单文件 index.html
npm run compare        # 逐页截基线 + 新页 + 生成左右等宽对照图
```

产物：

```
shots/baseline/   基线 5 页（首页 / L1 地球 / L2 全国地图 / L3 省区面板 / L4 单品链路）

shots/compare/    6 张左右对照图（同视口等宽缩放）
  cmp-01 基线品牌首页            ↔ 事实层
  cmp-02 基线 L2 地图 + 右侧面板 ↔ 事实详情
  cmp-03 基线 L3 省区分析面板    ↔ 关联层图谱
  cmp-04 基线 L1 全球地球        ↔ 关联层地理关联
  cmp-05 基线 L4 单品全链路      ↔ 推演层（五阶段十二步骤）

```

## 一、视觉体系：设计令牌（token 级复用）

`src/v03/app.css` 的 `:root` 从基线 `app.css` 继承，同名同值 **21 项**：

```
--panel --panel-2 --line --ink --mut --dim --hint --accent --accent-soft --green
--orange --purple --warn --warn-bg --s2 --s3 --s4 --s5 --s6 --s7 --ease
```

- 间距七档（`--s2…--s7`）、缓动 `--ease`、强调色 `--accent:#1d4ed8`、次要文本三档灰阶全部与基线一致；
- `--hair`（虚线分隔）本轮已对齐基线值 `rgba(20,30,55,.11)`；
- 新增 token 仅 10 项，都是新结构必需的：`--bg`、五类事实分类色（`--policy/--price/--weather/--logistics/--trade`）、`--red`、`--s1`、`--ctl-h/--stream-h`（面板高度变量）。
- 数字排版沿用基线的 `font-variant-numeric: tabular-nums`（基线 `.num/.kpi .v/...` 规则），新页 KPI、指标、轮次数值同样适用；
- 可访问性沿用基线的 `:focus-visible` 外圈规则。

## 四、已知差异（如实列出）

| # | 差异 | 原因 / 处置 |
| --- | --- | --- |
| 1 | 未保留基线品牌首页（`#landing`） | V0.3 的信息架构是三 TAB 直接进入；验收记录为观察项。如需回归品牌首页，属于结构变更，需另行确认 |
| 2 | 按钮圆角 9px（基线 12–14px） | 本轮要求「保留现有视觉与交互，不推翻重做」，未调整；如需对齐可单独提一条 |
| 3 | L1 用 ECharts 世界地图，未用基线 canvas 地球 | 基线地球绑定 L1–L4 流向数据模型，而事实层评审结论明确「不显示线路、流向线」，故只做点位与影响范围 |
| 4 | 媒介（图文/视频/直播流）为占位素材 | 无真实素材源；页面已标注「示意素材」 |
| 5 | 基线 AI 问答 / 配置中心未接入 | 属旧应用层，已归档 `legacy/agrilink-l1l4/`（含说明） |

## 五、对照结论（供验收复跑）

- 颜色、字体、间距、缓动、数字排版与基线同源（token 级 21 项一致，素材 6 个文件字节级一致）；
- 地图/图谱仍由同一 ECharts 与同一份 geo 数据渲染，交互沿用基线的相机飞行与 geo 点击模型；
- 新增的三层结构（事实层 / 关联层 / 推演层）与底部流水、九类对象域、五阶段十二步骤属于本轮内容增量，在基线视觉语言内实现。
