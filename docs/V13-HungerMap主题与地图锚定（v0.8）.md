# V13 · HungerMap 主题与地图锚定（V0.8）

## 本版范围

1. 参考 HungerMap LIVE 的日间 / 夜间地图与面板配色，默认夜间；顶部设置按钮左侧增加主题切换图标。
2. 夜间 3D 视角增加地球缓慢自转、深色大气层与独立视差星空。
3. 修复事实点与地图在拖动 / 缩放时产生分层观感的问题。
4. 数据概览由连续匀速递增改为不规则批次：间隔、增量均变化，并允许空窗。

## 地图缺陷根因与修复

旧版静态点虽然绑定 ECharts `geo`，但影响力扩散动画使用了独立 DOM Canvas；密度点又使用 `large + progressive` 独立绘制路径。旧回归只验证 `convertToPixel()` 的理论投影变化，没有验证真实绘制层，因此无法阻止“底图先动、覆盖层后跟”的分层观感。

V0.8 将密度点、事实点、影响圆和扩散动画统一放进 ECharts 的同一个 `geo` 坐标系，移除独立 Canvas；密度层关闭 `large + progressive`。新回归读取各真实系列的 item layout，拖动后四层位移必须在 1px 内一致，并覆盖 2D 拖动、3D 自转与星空动画。
