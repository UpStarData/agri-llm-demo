# v07 第五轮修改记录（事实层 · 数据体量与地图交互）

> 依据：产品第五轮口头反馈（数据概览/地图交互/点样式/数据体量）。本轮仍只改事实层与共用框架。

## 一、数据概览与实时感

- 事实条数改为**数据库体量口径**：按「每个三级事实类型」的下限配额计算 —— 全球 100 万/类型、中国 10 万/类型、省区 1 万/类型；
  左侧概览显示如 `1.25 亿`（`V03Mass.fmt` 自动用 万/亿 单位），下方小字注明「每个三级类型 100 万 条 · 本视野采样 2400 点」
- 新增「**实时接入 +N 条 / 今日**」计数：底部流水每处理一条事实，概览数字**滚动 +1**（`numTick` 动画），地图同步闪星，
  右侧卡片流顶部插入一张带「新接入」标记的卡片（最多保留 12 条）

## 二、地图交互（明确范围）

| 规则 | 实现 |
| --- | --- |
| 全球铺满屏后不能再缩小 | L1 `scaleLimit.min = 1.06`（= 铺满），滚轮/按钮缩小到该值即停 |
| 全球放大到一定程度 → 中国视角 | L1 放大到 2.2× 自动切 L2（中国地图） |
| 中国缩小 → 回到世界地图 | L2 缩小到 0.9× 以下自动切回 L1 |
| 中国放大到湖南位置 → 湖南视角 | L2 放大到 2.9× 且视野落在某省中心 3.4° 内 → 切 L3（默认湖南） |
| 湖南视角还能放大 5 次，之后不能再放大 | L3 上限 4.2×3.4 ≈ 14.3（= 按钮 1.28 倍连点 5 次），到顶后 `+` 按钮禁用、滚轮也被 `scaleLimit` 拦停 |
| 滚轮缩放 / 拖拽平移 / 双击放大 | `roam: true` + 双击 1.35×；缩放决策统一走 `afterZoom()`，滚轮与按钮行为一致 |

## 三、地图视觉

- **地图铺满整屏**：地图容器 `inset: 0`，右侧卡片面板与抽屉改为**浮在地图之上**（不再挤压地图宽度）
- **毛玻璃更明显**：面板底色 `rgba(255,255,255,.62)` + `blur(24px) saturate(180%)`，抽屉/卡片面板能透出后面的地图
- **事实点统一红点**：去掉分类配色，统一 `#d63c3c`，大小仅随重要性（4.6 / 5.2 / 6px），与关联层本体点风格一致
- **扩散动画重做**：高影响事实改为「一圈缓慢扩散的细红环」（6s 一轮、2 圈、极淡描边），替代原先刺眼的环形脉冲；
  普通事实只保留极淡的径向范围圈（透明度 ≤0.16），不再整屏光晕
- **质量级采样点阵**：地图底层新增采样点（全球 2400 / 中国 2200 / 省区 1800），围绕真实锚点（产区/口岸/省中心）确定性分布，
  颜色 `rgba(214,60,60,.42)`、2.1px，只表达密度、不参与交互（tooltip 显示该视野体量与采样说明）

## 四、直播可见性

- 已核验可嵌入的直播卡（CCTV 系列）**不受事实筛选影响，常驻卡片流顶部**，因此在默认「近 7 天 + 高可信 + 高影响」下也能看到直播流卡片

## 五、数据体量与展示方案（说明）

产品定义的是**数据库体量**（每个三级类型 1 万 / 10 万 / 100 万条），浏览器不可能逐条渲染上亿条记录，因此分两层：

| 层 | 内容 | 交互 |
| --- | --- | --- |
| 体量层（质量级采样） | 按配额计算的体量 + 围绕真实锚点确定性采样的 1800–2400 个点 | 不交互，tooltip 显示体量口径 |
| 事实层（可交互） | 934 条真实结构事实（含第三方补充：机场 900、天气 37、重点农产品 36） | 点击看详情、联动卡片与流水 |

每一级视野的采样点数与体量都会在概览与 tooltip 中标注，避免把采样点误读为逐条事实。
