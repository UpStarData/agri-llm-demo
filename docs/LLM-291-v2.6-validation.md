- 新资料主要是农业生产、供需、政策、产销和公开新闻，也含物流、价格、通关报道。只摘录标题和出处，不从标题推造价格、成交量、供应关系或企业本体。没有将所有资料改成“实时新闻”。新增报道的分类计数：新闻 3,450、生产 2,815、政策 627、供给 400、流通 148、物流 18、价格 9、通关 14。

`v26-reports-source.json` 冻结 7,815 条来源元数据及未成功抓取的分页列表；失败页没有变成事实。`v26-reports.json` 是去重、剔除天气及纯内部活动等内容后的选集。工具可重复构建：

```
python3 tools/collect-v26-reports.py
node tools/collect-v26-hebei.mjs
python3 tools/collect-v26-areas.py
python3 tools/build-v26-reports.py
```

逐条的准确索引及原文 URL 以冻结元数据为准。行政代表点来自 DataV 公开区划中心，冻结于 `v26-areas.json`；标题有明确县市名时归到该县市，否则只定位到省级代表点，河北仅归石家庄。新增报道共 429 个独立行政代表坐标，`geoPrecision=region_only`，卡片/详情明确“行政区代表点，不代表具体农场、企业或交易发生地点”。不抖动坐标，不伪造农业设施分布。历史日期保留，长期资料点不因旧的事件时间衰减而变成完全透明。

原演示基线的 `generated` 标记不变；不能将整个 14,318 条归档宣称全为真实实时报价。

## 渲染、卡片与图谱

1. 关联首绘：旧路径先 `series:[]/notMerge`，再整体替换，而且入场 `t=0` 导致空节点帧。本版先准备完整 option，单次首绘，入场从微小非零进度开始；省区线在新投影就绪后做局部裁剪更新。三视角探针各一次全量重建，空系列和空节点 paint 均为零。
2. 后续不影响业务几何的事实入库仍零 `setOption`，相机、底图和全部原有节点图元保留；已有视角不重播入场，抽屉不重建流动动画。
3. 图谱使用当前 `F.objects/F.relations`；界面显示过滤总量、实际显示量、最多 220 节点和子网选取规则。默认 5,191/4,098 中显示 220/371；榴莲筛选 94/216 全量显示；本体分类、关系类型组合也逐条验证边 ID 与端点，错配为零。此处“经营品类”是旧数据实际类型，不改造为虚构新关系。
4. 右卡去掉无关系或无公开来源的渠道，以及小超市、果蔬小店、便利店、日杂等细粒度零售。大型连锁按验收白名单（永辉、步步高、人人乐、沃尔玛、Costco 等）匹配，且有公开来源与关系才保留；不根据名字有“大”字判断面积。已有同名分店保留真实不同 ID，不冒充多家集团。底层实体和历史关系未因卡片清理而删除。
5. 新事实采用 96 篇尚未在本会话入库的真实报道，每 7.5–12 秒检查当前可见地域，经同一 `D.ingest` 路径入库、亮 V0.8 DOM 星、右卡置顶。报道原日期与入库日期分开。有限队列耗尽时明确“接入回放”，不编造实时报道。新本体也只接受有来源的业务目录实体；被卡片策略排除的小店不作为新卡通知。

## 验证与性能边界

- `npm run test:all`：既有影响半径、地图颜色/循环副本、拖动同步、入库去重、动画实例等回归。
- `npm run test:v26`：八省市地图量与禁用类型、归档可查、长期资料点实际不透明、真实报道入库、三视角首绘、零售卡片、四组图谱计数/边端点；地域/红星回归、历史投影与真实中国→湖南下钻、实际关系线及移动粒子点击详情。
- `node test/v26-delivery.mjs`：不手动完成加载，不调用手动接收入口，观察 32 秒批次与两层六个 2D、两个 3D 自然到达亮星/卡片。
- `node test/v24-interactions.mjs`：六视角实际缩放及稠密事实真实指针点击；完整载入后独立切换/缩放未观察到 ≥50ms 长任务。
- 首轮自然加载实测约 **32,049ms** 完成，阶段记录 7,032 → 10,462 → 13,891 → 14,320（包含真实到达两条）。该轮互动长任务最长 **81ms**；启动最长 **155ms**，如实保留初始化开销。不是宣称所有启动任务低于 100ms。
- 单文件约 36MB，数据仍随 HTML 下载，32 秒是显示分批，并非网络流式下载。地图按独立坐标合并、有界绘制；不通过加入隐藏的天气/目录来满足地图体量。
