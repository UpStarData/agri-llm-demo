## 启动

```bash
npm install          # 仅 Playwright，用于测试与截图
npm run build        # 生成单文件 index.html（离线可用，直接双击即可）
npm run serve        # 本地演示服务（默认 127.0.0.1:4173，静态托管同一份文件）
```

构建产物就是仓库根目录的 `index.html`（约 3 MB，CSS / JS / echarts / 地图 geo / 4 个字重全部内联，无任何外部请求）。

## 本轮改了什么（LLM-291）

| 区域 | 内容 |
| --- | --- |
| 全局 | 品牌统一为 `🌾 AgriLink v1.0`；IBM Plex Sans SC 四档字重（300/400/600/700）；面板毛玻璃 + 底部纯黑终端；稻谷 Logo 刷新抖动；所有面板与弹窗去标题栏；界面不再出现「示意数据」字样 |

| 左侧图层菜单 | 从左侧滑出，三层结构：数据概览 → 三级分类筛选（一级标题 / 二级子标题 / 三级 emoji 方块卡片，默认全选）→ 快捷控制（M1–M11 + 地图快捷键总开关 + 图例） |

| 弹窗 | 事实详情、本体详情、关联详情统一重排为两列紧凑面板（小字号、发丝分隔、键值对 + 条状指标） |

### 数据包定向接入（LLM-292）

| 要求 | 落点 |
| --- | --- |
| ①事实 / 本体 / 关系与产区 / 港口 / 机场改读完整包 | `data/pkg/`（整包入仓，构建内联）+ `src/v03/pkg-adapter.js` |
| ②拆分事实数据与推演数据别名 | `D.FACTS…` = 数据包；`D.BASE_*` = 自带数据别名，`data-sim.js` 与 run / 报告未被覆盖 |
| ③按 `cardType` 接入六类卡片 | `src/v03/fact.js`：news / policy / price / weather / video / market |
| ④加入 Person 类型 | 九类对象域含「人物角色」（14 个本体对象，首屏面板可见） |
| ⑤接入 regions / ports / airports / nodes 与 stream.sequence | M5 / M6 图层共 173 个真实点位；底部流水与地图新星由 1135 条时序事件驱动 |
| ⑥内部保留 provenanceMeta / dataMode | `V03_DEBUG.provSummary()`；UI 不出现任何来源或样例文案 |

## 主路径

`事实层总览（全球 → 全国 → 省区）→ 事实详情与证据 → 携带事实进入关联层 → 本体与关系（地图 + 清单）→
本体详情 / 关联详情 → 加入推演种子 → 推演配置与阶段 → 轮次过程 → 报告与引用`

推演层为统一用户故事：**马来西亚榴莲流入红星市场的占比** 与 **红星市场在湖南榴莲交易量的市场份额**，贯穿五阶段十二步骤。
