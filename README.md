# 农链 AgriLink · 中国农产品产业地图（阶段演示）

面向农博会 / 集团展示场景的**阶段性领导演示 Demo**，用于确认展示形态与信息结构。
线上：https://upstardata.github.io/agri-llm-demo/

> ⚠️ 页面内**所有数值均为示意数据（待标定）**，仅用于表达信息结构；
> 口径字段为真实口径框架（海关贸易量 / 产区供给规模 / 省际调运量 / 环节台账 / 元·kg）。

## 这是什么

一张可下钻的中国农产品产业地图，四层主线，逐层由**数据对象**驱动下钻：

| 层 | 分析对象 | 视觉语言 |
| --- | --- | --- |
| L1 全球货源流向 | 境外来源国 → 中国 | 自动旋转地球 + 按贸易量依次长出的流向弧与流光 |
| L2 全国产区与省际流通 | 省（产区）+ 省际调运 | 中国地图 + 供给规模气泡 + 按量级依次点亮的调运线 + 进口直达图层 |
| L3 省区产业分析 | 省内城市 / 产区 | 相机推进该省 + 城市节点 + 品类结构条 + 竞争力雷达 |
| L4 城市代表单品全链路 | 本地代表单品 | 六环节流程轴（种苗→种植→采后→冷链→批发→零售）+ 价格链路 + 经营主体抽屉 |

交互要点：层间 **1.2–1.6s Prezi 式相机切场**（不白屏、不换页）；**没有「下一步」按钮**，
导航发生在数据对象上；滚轮缩小 / 点空白 / Esc / 面包屑都能返回上一层并恢复上层位姿；
每层右侧嵌入**基于当前选中对象**的 AI 分析助手。

## 使用

- **线上**：直接打开 https://upstardata.github.io/agri-llm-demo/
- **离线**：双击 `index.html`（单文件，字体/地图/图表/世界边界全部内联，无任何网络请求）

## 构建与测试

```bash
node build.mjs        # src + vendor + data + fonts → index.html（单文件）
node test/e2e.mjs     # Playwright 桌面端 + 移动端端到端测试 → test/report.md 与 shots/
```

测试直接以 `file://` 加载单文件，并拦截全部外部请求 —— 同时验证离线可用与零控制台错误。

## 目录

```
index.html          # 构建产物：单文件、零外部依赖（发布对象）
build.mjs           # 构建脚本
src/                # 源文件（shell.html / app.css / data.js / globe.js / ai.js / map.js / app.js）
data/               # 中国省级边界、世界国界（构建时内联）
vendor/echarts.min.js
fonts/              # IBM Plex Sans SC 子集（构建时 base64 内联）
test/               # e2e.mjs + report.md
```

## 边界

- 本 Demo 为**独立阶段性演示**，不关联、不替代长期"农产品交易大模型"。
- 竞品功能清单未获取（参考文档需登录），本期未与具体竞品逐项对照。
- 主体级数据（L5）尚未成立，仅以 L4 内的「经营主体抽屉」确认信息结构。
- AI 助手为规则化应答，用于确认形态；接真实模型时替换 `src/ai.js` 的 `ask` / `free` 两个入口。
