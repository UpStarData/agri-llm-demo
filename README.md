# 农业数据三层推演平台 V0.3 · 事实层 / 关联层 / 推演层（Demo）

在浅色基线 [AgriLink](https://upstardata.github.io/agri-llm-demo/)（原提交 `46be371`）的**代码与视觉体系**上改写的新 Demo。
信息架构只有一个业务链条：**事实层 → 关联层 → 推演层**；报告是推演层的结果页，不是第四个 TAB。

> ⚠️ 全部数值为**示意数据（待标定）**，仅用于确认展示形态与信息结构；口径字段为真实口径框架。
> 推演层为**离线示意引擎**，不是真实 MiroFish / Jev-like 后端运行。

## 启动

```bash
npm install          # 仅 Playwright 用于测试与截图
npm run build        # 生成单文件 index.html（离线可用，直接双击即可）
npm run serve        # 本地演示服务（默认 127.0.0.1:4173，静态托管同一份文件）
```

构建产物就是仓库根目录的 `index.html`（约 2.3 MB，CSS/JS/地图 geo/字体全部内联，无任何外部请求）。

## 主路径

`事实层总览（地图） → 事实详情与证据 → 携带事实进入关联层 → 关系图谱 / 地理关联 → 关系详情与回溯 → 加入推演种子 → 推演配置与七阶段 → 轮次过程 → 报告与引用 → 回到对应事实 / 轮次`

三条场景均为样例：**水产补贴套利**、**基地—湖南—红星供需与谈判**、**价格影响链**。

## 三层各做什么

| 层 | 主体 | 关键交互 |
| --- | --- | --- |
| 事实层 | 地图（点 + 影响范围） | 时间/分类/二级/来源/可信度/影响度筛选、空间下钻（全球 → 中国 → 省区）、事实卡片（图文/视频/公开直播流）、事实详情（影响范围、证据、相关本体对象与关系）、加入推演种子、底部数据接入与处理流水 |
| 关联层 | 关系图谱 / 地理关联双视图 | 九类对象域分类、对象与关系详情（强度/置信度/形成时间/最近变更事实/支撑事实/时序记忆）、社区摘要、携带事实高亮、无坐标对象清单、底部本体抽离与关联处理流水 |
| 推演层 | 七阶段流水线 + 轮次 + 报告 | 种子确认、开始/暂停/单步/回放/重置、GraphRAG 子图、农业角色 Agent 配置、逐轮详情与信号、报告逐步生成与引用回链、Jev-like 旁路信号面板（可模拟降级）、离线回放、失败重试 |
