AgriEmoji · 5 个图层图标的子集字体用法

① 最简：把 emoji 字符放进带 agri-ic 类的元素里

🌾产区 ⚓港口 ✈️机场 🏪农贸市场 ⚠️地缘风险区 
<span class="agri-ic agri-ic--lg">✈️</span>

② 不写字符：只用类名（语法糖，靠 ::before 输出字形）

产区 港口 机场 农贸市场 地缘风险区 
<i class="agri-ic agri-ic--md agri-ic--airport"></i>

③ 地图锚点式（图标是 DOM 层，位置 = 经纬度换算的像素）

<span class="pin agri-ic agri-ic--md agri-ic--airport" style="left:48%;top:38%"></span>

④ ECharts（我们线上就是这么用的：label 指定字体）

{
  type: 'scatter', coordinateSystem: 'geo',
  symbol: 'circle', symbolSize: 13,
  itemStyle: { color: 'transparent', borderWidth: 0 },   // 不画圆底
  label: {
    show: true, position: 'inside',
    fontFamily: 'AgriEmoji, Apple Color Emoji, Segoe UI Emoji, Noto Color Emoji',
    fontSize: 13,
    formatter: () => '✈️',                                 // 或 '\u2708\uFE0F'
    backgroundColor: 'transparent', padding: 0, textBorderWidth: 0
  }
}

注意：不要用 itemStyle.opacity:0 藏圆点——label 会一起被隐藏，emoji 直接消失；用 color:'transparent'。

字体：agri-emoji.woff2（26KB，Noto Color Emoji 子集，OFL-1.1）· 样式：agri-emoji.css。透明 = 元素不加 background/border/box-shadow，字形外即底图。
