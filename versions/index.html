仓库根地址 /agri-llm-demo/ 显示的就是 V0.0（和 /v0.0/ 是同一份文件）；以后每次发版在最新版本上加一个号（当前 V0.8.2），旧版本地址一直保留。

版本目录页：/agri-llm-demo/versions/ · 源码在同一个仓库的 llm-291/v1-fact-relation-redo 分支，每个版本另有 git tag（v0.4.0 … v0.8.2）。
新增版本的做法：把构建产物放进新目录 vX.Y/（含 index.html + build-meta.json），更新本页与仓库根目录 VERSIONS.md，不再新建仓库。
