版本目录页：/agri-llm-demo/versions/ · 源码在同一个仓库的 agent/mika/llm-291-perf-fix 分支，每个版本另有 git tag（v0.4.0 … v0.8.4）。
新增版本的做法：把构建产物放进新目录 vX.Y/（含 index.html + build-meta.json），更新本页与仓库根目录 VERSIONS.md，不再新建仓库。
