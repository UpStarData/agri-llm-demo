- 这些文件**不参与当前构建**（`build.mjs` 只内联 `src/v03/*`），仅为可追溯性与对照保留。
- 对照价值：浅色设计令牌、ECharts 地图机制（`map.js` 的相机飞行 / geo 点击）、L1–L4 空间放大叙事、AI provider 适配。

- 原基线测试（`test/e2e.mjs` 等）依赖旧 `index.html` 结构，已随基线一并归档，不再运行。
