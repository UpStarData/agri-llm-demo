# 一、需求背景

农业经营判断需要同时理解天气、政策、价格、交易、物流等信息。这些信息分散在新闻、报告、业务记录和结构化数据中：单独看一条消息，难以判断它涉及哪些品种、地区和经营主体；单独看一张报表，也难以追溯变化的原因。

AgriLink 农链面向农业经营管理与分析场景，将分散材料整理为可核对的现实事实，识别事实涉及的产业本体及有依据的关系，再围绕具体事件或经营方案开展推演。用户能够从一条信息出发，查看它与品种、地区、企业、市场及供应链环节的联系，分析采购、促销、调运等行动可能带来的变化，并沿分析结果回到原始依据。

本版本面向 11 月 15 日展示，围绕「事实层 → 关联层 → 推演层」建立从数据到决策分析的完整业务过程。事实层和关联层提供现实依据，推演层在独立的模拟环境中评估变化，形成能够解释过程、核对依据的决策报告。

本文档按已确认的产品方案整理。未经明确确认的功能、仍在研究的方案及后续独立事项，不在正文中描述为既有能力。

# 二、需求价值与目标

## 2.1 需求价值

| 价值点           | 说明                                                                          |
| ------------- | --------------------------------------------------------------------------- |
| 证明专业数据的价值     | 少量但专业、可追溯的农业数据，经过事实结构化和关系连接后，能够支持经营问题的定位与分析，形成单张报表以外的价值。                    |
| 证明 LLM 在其中的作用 | LLM 参与材料抽取、分类、本体识别、关系判断和推演分析，将分散信息转化为可解释的分析结果；<br>事实、计算、推断和模拟分别表达，结果能够追溯依据。 |

## 2.2 产品目标

| 目标          | 说明                                                       |
| ----------- | -------------------------------------------------------- |
| 事实可解释、可追溯   | 每条事实记录时间、位置、分类和来源；<br>字段缺失时显示未知，不生成虚假值；<br>来源、证据和处理记录可从详情查看。     |
| 关联有依据       | 本体对象和关系均绑定支撑事实；<br>没有证据的关系不作为既成事实写入；<br>关联图谱和事实层可双向跳转。           |
| 推演与现实隔离     | 推演在独立 `run_id` 下运行；<br>推演过程产生的事实、对象、关系变化不写回现实数据；<br>现实数据不因推演而改变。 |
| 报告内容可区分、可回溯 | 报告明确区分现实事实、模型推断、模拟结果和行动建议；<br>每项判断可回溯到支撑事实、推演轮次或计算来源。        |

## 3.3 首发展示品种

首发展示数据向以下三类品种倾斜，但产品功能不依赖特定品种：

1. **榴莲**：高价值进口水果，适合展示产地、海关、物流、汇率、政策、天气和价格传导。
2. **车厘子**：高价值、强季节性水果，适合展示产季、冷链、港口、损耗、渠道和价格变化。
3. **辣椒**：代表性高价值蔬菜，适合展示产区、天气、生产成本、批发市场、库存和消费变化。

榴莲和车厘子已经确定；辣椒作为代表性蔬菜暂定。后续如果样本数据证明其他蔬菜更适合，只调整演示数据，不改变产品结构。

## 3.5 整体业务流程

### 3.5.1 系统数据处理流程

系统在后台持续处理来源材料，事实抽取与关联识别不以用户打开页面为触发条件：

1. **接入材料，形成事实。** 系统接入新闻、报告、业务记录及结构化数据，提取能够独立表达的事实，记录时间、位置、分类和来源。一份材料可以形成多条事实；同一事实也可以由多份材料共同支持。
2. **识别本体，统一身份。** 系统识别事实中出现的企业、市场、基地、品种等本体对象，将不同事实中指向同一对象的信息归到同一本体下。
3. **建立关系，保留依据。** 系统根据事实识别本体之间的关系，经过本体合法性校验、自动评分后写入关联数据，保留关系方向、时间和支撑事实。
![[三层整体业务主线.png]]
### 3.5.2 用户分析与推演流程

1. **查看事实，核对依据。** 用户通过事实分类、地图或卡片找到关注的事件，在事实详情中了解事件内容、相关范围及来源。
2. **查看关联，理解联系。** 用户从事实进入关联层，查看相关本体、关系及支撑事实，了解事件涉及的产业对象和经营环节。
3. **确定问题，准备推演。** 用户选择事实、本体或关系作为推演起点，结合经营方案明确要判断的问题、品种、区域和时间范围。系统汇集相关现实依据，并区分已有事实、用户假设和经营动作。
4. **建立环境，运行模拟。** 系统根据本次问题建立独立推演环境，组织相关对象、关系、角色和运行参数，模拟事件或经营动作引发的连续变化，记录各轮过程和结果。
5. **形成报告，解释结果。** 系统汇总关键变化、影响路径、风险、机会和数据缺口，生成决策报告。报告分别表达现实事实、模型推断、模拟结果和行动建议，并保留对应依据。
6. **追溯依据，继续分析。** 用户从报告结论查看对应的推演过程、现实关系和原始事实，并围绕报告继续追问；需要改变假设时，保留原推演记录，另行开展新的推演。

## 4.2 事实层

**需求背景**：农业经营判断依赖的信息来源分散、格式各异，且不同来源的内容可能指向同一事件，也可能相互冲突。事实层的作用是把来源材料整理为有时间、有位置、有分类、有来源的事实，让用户能够在一个入口查看正在发生什么、已发生的事实有哪些支撑依据，并从事实出发进入关联分析和推演。

**页面路径**：「AgriLink」-「事实层」。

**页面结构**：

- 顶部：菜单开关 + Logo（左）、三层 TAB（中）、快捷键组（右，含日志开关 / 卡片开关 / 日夜模式 / 设置预留）；
- 左侧菜单（浮层，可收起）：数据概览 / 图层数据分类筛选 / 叠加数据图层 / 快捷控制；
- 中间：事实地图（永久背景），地图右下角浮层为地图操作快捷控制组；
- 右侧（浮层）：事实卡片列表；点击事实点或卡片后，事实详情从卡片列表左侧滑出，卡片列表仍可见；
- 底部（浮层，可收起）：来源材料接入与事实处理日志。

- 换算结果 < 8px 时，不绘圆，只保留事实点；
- ≥ 8px 时绘圆。
- 圆超出当前视口边界时，按原尺寸绘制，透明度降至 30%，不截断。

**地理影响半径说明**：Jev 根据事实内容估算的地理影响范围（单位 km），用于绘制事实点外的影响圆。**半径是事实的固定值，不随地图视角改变。**


**地理影响半径估算规则**（供 Jev 参考）：

| 事实类型 | 估算方式                    | 示例                          |
| ---- | ----------------------- | --------------------------- |
| 天气灾害 | 根据气象预警范围、受灾面积           | 台风影响半径 300-500km            |
| 政策   | 根据政策适用地理范围              | 省级政策 ≈ 200km，国家级政策 ≈ 1000km |
| 价格市场 | 根据市场辐射范围                | 产地市场 ≈ 50km，批发市场 ≈ 100km    |
| 物流交通 | 根据基础设施服务半径              | 港口 ≈ 150km，机场 ≈ 200km       |
| 生产供给 | 根据生产主体规模和产品流通范围         | 大型基地 ≈ 100km，小型基地 ≈ 30km    |
| 无法估算 | 证据不足、无明确地理信息、或影响范围高度不确定 | 标记为"未知"，不绘圆                 |

**重要说明**：

- 半径为 Jev 估算值，不是测量值；提示词需提供已确认样例，让 Jev 按相同尺度判断
- 证据不足时返回"未知"，不硬凑数字
- 圆的显示由地图引擎根据像素阈值判断，半径本身不变


> **显示层级与地理影响圆的关系**：
> 显示层级决定事实点在哪个地图视角出现；
> 地理影响圆大小反映 Jev 估算的地理范围；
> 事实点大小统一，不随显示层级或地理影响范围变化。

**给爬虫工程师的说明**：

4. 一份材料拆成多条事实时，由 Jev 根据媒体附近的文字判断它属于哪条事实，**判断不出时不挂载**；
5. 没有真实材料时，准备带原始媒体的来源材料（带视频、图片的网页或文章），让抽取流程真实提取媒体，**不直接写好带媒体的演示事实**；

#### 4.2.4.2 分类型字段

**设计原则**：事实详情由"共同字段 + 分类型字段"两部分组成。

### 4.2.6 事实处理规则

本节说明系统在后台处理来源材料、生成事实时的核心规则，用于开发核对与测试验收。规则为产品要求的可见结果；底层实现方式由开发提出方案。各功能的触发、输入、处理、输出见 4.2.7，完整样例见 4.2.8。

| 规则          | 处理逻辑                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| 来源材料与事实拆分   | 来源材料不是事实本身；<br>一条事实也可以关联多个来源材料或证据。                                                                             |
| 事实字段提取      | 系统按事实类型提取发生时间、地区、农产品、指标及其他适用字段，并保留字段对应的来源依据。无法从材料中确认的信息保持缺失，不根据常识补写；<br>来源发布时间不得直接作为事实发生时间。                    |
| 去重与冲突检查     | 多份材料指向同一事实时，保留各自的来源和证据；<br>来源内容相互冲突时，并列保留相应信息及来源，不静默覆盖;<br>**Jev 模型** 在此步骤评估候选事实的冲突概率，辅助判断是否需要标记为"存在冲突"或"待补证"。 |
| 指标口径        | 展示或比较指标时保留币种、计量单位和统计周期等口径信息；<br>口径不一致或缺失时，不直接合并为可比数值。                                                          |
| 显示层级判断      | **Jev 模型** 根据事实内容、影响范围和证据质量判断显示层级（全球/中国/湖南/不显示），记录判断依据。层级判断规则见 4.2.2.1。                                        |
| 地理影响半径估算    | **Jev 模型** 根据事实内容估算地理影响范围（单位 km）；<br>证据不足时标记为"未知"，不硬凑数字。半径估算规则见 4.2.2.2。                                           |
| 本体与事实分类分离   | 公司、市场、基地、品种、政策机构等是关联层的本体，不作为事实分类。事实分类表达"发生了什么类型的事情"，本体表达"事实涉及谁"，两者分别维护。                                        |
| 本体候选识别与 Jev | 事实写入后，**Jev 模型**自动推荐"本条事实可能涉及哪些本体"，作为候选结果预填入事实详情的「涉及本体」字段。候选为建议而非确认关联；<br>用户进入关联层后可进一步核实。此机制加快从事实到关联层的路径，减少手动查找。   |
| 演示样本标注      | 演示样本的来源名称后必须带标签（如"模拟样例"）；<br>不在事实上另设数据状态字段。 |

# 附录 A 事实抽取智能体提示词骨架

**说明**：以下提示词是事实抽取智能体的结构规范，对应事实处理流程（4.2.5）中的内容解析 → 事实切分 → 分类 → 字段抽取 → 显示层级判断 → 地理影响半径估算步骤。提示词决定了事实字段填充的质量、缺失字段的处理方式和输出结构。产品支持在管理界面查看和编辑此提示词。

```text
你是农业事实抽取智能体（Jev）。请只依据给定材料，按照指定事实分类和字段规范提取事实。

要求：
```
