# 四、产品方案细节（关联层）

## 4.3 关联层

**需求背景**：事实层回答"发生了什么"，关联层回答"事实涉及谁、它们之间是什么关系"。关联层把事实中反复出现的产业对象整理为本体，把事实中写明的联系整理为有方向和有依据的关系，让用户能从一个品种或一条事实出发，看到相关的产区、港口、市场、企业、政策和事件，并沿关系回到支撑事实。

**页面路径**：「AgriLink」-「关联层」。

**页面结构**：

- 顶部：同事实层（菜单开关 + Logo、三层 TAB、快捷键组）；
- 左侧菜单（浮层，可收起）：数据概览 / 本体分类筛选 / 品种筛选 / 关系筛选 / 快捷控制；
- 中间：关联视图，3D 地球（默认）/ 2D 地图 / 图谱，右下角浮层为地图操作快捷控制组；
- 右侧（浮层）：本体卡片列表；点击本体节点或卡片后，本体详情从卡片列表左侧滑出，卡片列表仍可见；点击关系后，关系详情同样从卡片列表左侧滑出；
- 底部（浮层，可收起）：本体识别、身份归一与关系处理日志。

【📷 原型图：关联层整体布局】

| 区域   | 关联层内容                                                               |
| ---- | ------------------------------------------------------------------- |
| 左侧区域 | 数据概览（本体总数、今日新增本体、今日新增关系）<br>本体分类筛选<br>品种筛选<br>关系筛选<br>快捷控制 |
| 中间区域 | 3D 地球（默认）/ 2D 地图 / 图谱<br>右下角快捷控制浮层 |
| 右侧区域 | 当前筛选下的本体卡片列表<br>所选本体详情 / 所选关系详情 |
| 底部区域 | 本体识别、身份归一与关系处理日志 |

> **布局预留**：国庆后可能按领导要求把底部日志移到右侧、卡片移到左侧；这只是前端布局改动，本体、关系、日志的数据和接口不受影响，本期按上表开发。

### 4.3.2 关联视图

**页面路径**：「关联层」中间区域。

**页面说明**：关联视图是空间浏览与图谱分析的入口，有三种展示方式：3D 地球（默认）、2D 地图、图谱。三种视图共用同一套筛选条件，切换视图不改变图谱内容和卡片列表。地图是永久背景，图谱视图叠在地图上方显示。

**二维地图规则**：同事实层 4.2.2。支持左右滚动（东西向循环）；不支持上下循环；继续缩小到一定阈值时自动切换到三维地球。

**三维地球规则**：同事实层 4.2.2。显示为旋转地球，背景为星空；放大到一定阈值时自动切换回二维地图。

#### 4.3.2.1 本体节点与显隐

| 功能点     | 页面交互            | 页面说明                                                                                          |
| ------- | --------------- | --------------------------------------------------------------------------------------------- |
| 本体节点    | 【📷 原型图：本体节点样式】 | **逻辑说明：** 有坐标的本体在地图上表现为一个节点；<br>所有节点大小相同，不因类别或重要性放大，不使用分类图标；<br>没有坐标的本体不在地图上生成节点，只在右侧卡片列表中显示。 |
| 新节点亮起   | —               | **逻辑说明：** 新本体写入时，对应地图节点短暂亮起约 3 秒（建议值）；<br>不在当前视图中时不亮起，不移动地图。                                  |
| 同位置多个本体 | —               | **逻辑说明：** 本期点击默认打开最近写入的一个本体的详情；<br>后续再考虑多个本体的选择方式。                                            |

> 没有坐标的本体属于正常情况，是数据不足造成的，不作为错误提示。

**节点坐标来源**：Jev 从事实原文或预置清单中抽取坐标；抽取不到就没有坐标，不做额外推断。

#### 4.3.2.2 关系线与显隐

**页面说明**：3D 地球和 2D 地图以飞线表示关系，飞线的显示由本体节点和关系两端共同决定；图谱视图显示所有节点与关系，不受本节显隐规则限制。

**关系线的画法**：

| 属性 | 规则                                                             |
| -- | -------------------------------------------------------------- |
| 颜色 | 表示关系类型，按域分组（生产供应、经营组织、空间、物流、政策、影响），共 6 种颜色，图例见左侧关系筛选。 |
| 粗细 | 表示支撑事实数，分三档（建议值）：1 条为细，2–4 条为中，5 条及以上为粗。                   |
| 方向 | 有方向的关系线上画箭头；<br>合作（无方向，A 与 B 互换意思不变）线上不画箭头。                  |
| 流动 | 线上持续有光点沿方向流动；<br>无方向的关系（合作）光点双向流动。                             |

**关系线的显示层级**：层级由两端本体中地理范围更大（更宏观）的那端决定，不由两端中范围更小的那端决定。

| 层级   | 判断标准                   | 例子                                              |
| ---- | ---------------------- | ----------------------------------------------- |
| 全球层级 | 任一端是跨国级本体（位于不同国家）      | 智利中部产区 → 供应 → 长沙红星大市场（智利是跨国级，全球视角起显示）           |
| 中国层级 | 两端都在中国境内，且任一端跨省         | 上海港 → 运输至 → 长沙红星大市场（两端都在国内，但跨省，中国视角起显示）         |
| 湖南层级 | 两端都在湖南省内               | 邵阳县辣椒基地 → 供应 → 长沙红星大市场（两端都在湖南，只在湖南视角显示）         |

地图显示逻辑：
- 全球视角：显示全球、中国、湖南三个层级的关系线；
- 中国视角：显示中国、湖南层级；
- 湖南视角：只显示湖南层级。

**显隐顺序**：

| 步骤  | 规则                                                                         |
| --- | -------------------------------------------------------------------------- |
| 1   | **先定节点**：符合左侧筛选（分类、品种）且有坐标的本体才显示节点。                                        |
| 2   | **再定线**：两端节点都显示时画线；<br>一端在当前视角内、另一端在外，开启【跨区域关系】时也画线（见下方说明）；<br>两端都不显示时不画线。 |
| 3   | **像素阈值**：线的屏幕长度 < 8px 时不画，规则同事实层地理影响圆的阈值。                                  |

**跨区域关系**：

开启【跨区域关系】时，在地图上画出一端在当前视角内、另一端在视角外的关系线，表示这个视角里的本体和视角外的本体之间有关系。

例子：在湖南视角看长沙红星大市场，打开【跨区域关系】后，能看到一条飞线从视角边缘飞向红星，飞线的另一端延伸到视角外；缩放地图可以看到另一端是智利中部产区。

> 本期不做边缘标记和合并线；点击线默认打开关系详情，多条重叠时后续再考虑。

### 4.3.7 关联处理规则

本节说明系统在后台从事实生成本体和关系、构建图谱时的核心规则，用于开发核对与测试验收。规则规定可见结果和判定标准，底层实现由开发提出方案。

| 规则        | 处理逻辑                                                                                                                   |
| --------- | ---------------------------------------------------------------------------------------------------------------------- |
| 来源        | 本体和关系只有两种来源：事实（事实层写入触发）、预置（叠加图层清单：产区、港口、机场、市场、地缘风险区、行政区划）。                                                             |
| 触发        | 事实层每写入或更新一条事实，关联层处理一次；<br>事实被更正或撤回时，重新判定与它相关的本体和关系的证据状态。                                                               |
| 本体抽取与类型校验 | 以事实层 Jev 预填的本体候选为起点，由 LLM 补充抽取；<br>每个本体必须归入两级分类之一（地理与设施 / 主体与组织 / 农作物 / 事件，及其二级）；<br>归不了类的不写入，日志记录原因。                                                 |
| 关系 involved_varieties 维护 | 每条关系上维护 `involved_varieties` 字段（数组），存储该关系支撑事实中涉及的品种；<br>支撑事实写入、更新或撤回时同步更新；<br>品种筛选直接查询该字段，不做多跳查询。                                                 |
| 身份归一      | Jev 判断候选本体是否为已有本体（如"红星"与"长沙红星大市场"是否为同一个），是则复用并追加支撑事实，否则新增；<br>判断不了时不强行合并，新增本体并标记证据状态"待补证"。                             |
| 关系抽取与校验   | LLM 从事实原文中抽取关系，按下方约束表校验类型和方向；<br>不符合约束的不写入，只在日志中记录；<br>同一对本体、同一关系类型只存一条，新事实追加为支撑事实，不重复写入。                              |
| 冷启动图谱     | 系统级预生成图谱，20–30 个节点，覆盖榴莲、车厘子、辣椒相关的核心本体，随数据更新；<br>从 TAB 直接进入关联层时显示冷启动图谱。                                                 |
| 本体预生成图谱   | 每个本体一张，只取一层关系，按需生成并缓存；<br>该本体的关系变化时更新。                                                                                 |
| 上下文图谱     | 从事实详情进入时构建，以事实涉及的本体为起点，取预生成图谱并叠加本次上下文；<br>不写回数据。                                                                       |
| 重点本体      | 只在上下文图谱中有；<br>由 Jev 按本次上下文打分（依据：与上下文的距离、关系数量、支撑事实数），最多 10 个（建议值）；<br>结果只存在本次会话中，不写入本体；<br>重点本体在所有视角都显示，不受层级和【跨区域关系】限制。 |
| 上下文重建     | 上下文没变时，切出再切回不重跑；<br>品种、事实 ID、起点本体任一变化时，清空后重建；<br>点击【刷新】时，清空后重建；<br>缩放、切换视图、左侧筛选不算上下文变化。                                |
| 进入与返回     | 同事实层 4.1.2.1：<br>点击【关联本体】以该本体为起点；<br>点击【在关联层查看】以该事实已确认的本体和关系为起点；<br>返回事实层时恢复原状态；<br>没有数据时显示空图谱，不阻止跳转。                  |
| 演示样本标注    | 同事实层：演示样本的来源名称后带"模拟样例"标签。                                                                                              |

**关系类型约束表**（14 种）：

| 关系类型 | 颜色域  | 起点类别             | 终点类别                  | 方向          |
| ---- | ---- | ---------------- | --------------------- | ----------- |
| 生产   | 生产供应 | 产区与基地            | 品种                    | 有           |
| 供应   | 生产供应 | 产区与基地、企业与主体、品种   | 市场、企业与主体、地区           | 有           |
| 采购   | 生产供应 | 企业与主体、市场         | 企业与主体、品种              | 有           |
| 运营   | 经营组织 | 企业与主体、政策与机构      | 市场、港口与机场、产区与基地        | 有           |
